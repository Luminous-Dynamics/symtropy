# Upstream sample fixture: Armadillo Rollers / 3ee

This is a small excerpt from the public Scalable CCD sample dataset:
https://github.com/Continuous-Collision-Detection/Sample-Scalable-CCD-Data

Source files:
- `armadillo-rollers/queries/3ee.csv`
- `armadillo-rollers/mma_bool/3ee_mma_bool.json`
- `armadillo-rollers/boxes/3ee.json`

The source repository README documents that this query file has 16 rows (two edge-edge queries, eight rows per query), its Boolean file is `[false, false]`, and its box-pair file contains the two pairs shown here. The copied sample data and source repository are provided under Apache License 2.0; the license text is included at `LICENSES/Apache-2.0.txt`.

This fixture is intentionally small and is only an import-format smoke test. It is not the full NYU CCD benchmark and is not evidence of CCD algorithm accuracy or performance.
