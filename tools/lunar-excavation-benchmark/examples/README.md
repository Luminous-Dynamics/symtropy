# Synthetic fixture notice

Every file in this folder is illustrative only. The force trace and model configuration are generated arithmetic fixtures. The JSON example uses a synthetic material label and explicit zero-digest sentinels / synthetic-placeholder: paths for omitted model executable, particle-size, geometry, tool-path, as-built and parameter artifacts. It is deliberately **not admissible** as a physical benchmark record. It is not real JLU-H data, not a reproduction of any published paper, and must never enter a physical validation score.
