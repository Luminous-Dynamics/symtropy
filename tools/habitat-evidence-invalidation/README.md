# habitat-evidence-invalidation

Rust benchmark for evidence validity envelopes and dependency-scoped invalidation using synthetic data only.

From repository root:

```sh
cargo fmt --manifest-path tools/habitat-evidence-invalidation/Cargo.toml -- --check
cargo test --locked --manifest-path tools/habitat-evidence-invalidation/Cargo.toml
cargo run --locked --manifest-path tools/habitat-evidence-invalidation/Cargo.toml -- docs/research/fixtures/HABITAT_EVIDENCE_INVALIDATION_V0_1.json
```

No physical, permitting, survey-quality or regulatory claim is made.
