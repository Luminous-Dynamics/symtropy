# TAVIS result audit (Rust)

This tool audits native JSON outputs from the official TAVIS evaluator. It does not run Isaac Sim, load models, change policy actions, or re-score task success.

## What it checks

- Exact expected task/mode coverage, filenames matching embedded metadata, and expected episode count per cell.
- Native episode-success totals and Wilson 95% intervals.
- The TAVIS published pooled-success summary **and** an additional unweighted task-macro success mean, clearly labeled separately.
- GALT mean/median/valid count and reason-code counts over successful episodes, following the current TAVIS summary convention.
- Consistency of model, camera, robot, checkpoint path, control rate, and episode length across a run's files.
- Optional run provenance manifest and checkpoint/assets/environment SHA-256 fields.
- Stable episode IDs/seeds: when unavailable, the audit explicitly marks cross-run pairing as unavailable rather than aligning row order and calling it paired.

The inspected upstream `run_eval_episodes()` currently serializes success, length, wall-clock and GALT fields, but no explicit seed or episode identifier. Therefore cross-run paired episode analysis is disabled for such outputs until the upstream adapter logs stable identifiers. This is a deliberate statistical guard, not a missing convenience feature.

## Build and test

```bash
cargo test --manifest-path tools/vision-active-benchmarks/tavis-result-audit/Cargo.toml
cargo run --manifest-path tools/vision-active-benchmarks/tavis-result-audit/Cargo.toml -- \
  --run headcam=results/pi0-tavis-head-gr1t2-headcam \
  --run fixedcam=results/pi0-tavis-head-gr1t2-fixedcam \
  --expected-tasks clutter_pick_lift,clutter_pick_cube,conditional_pick,wait_then_act,multi_shelf_scan \
  --expected-modes id,ood_spatial \
  --expected-episodes 96 \
  --out-dir reports/tavis-head-gr1t2
```

Each directory must contain the per-cell JSON files produced by the official TAVIS evaluator. In strict mode, include `audit-manifest.json`, based on `audit-manifest.example.json`, in each run directory. Replace all placeholders with actual digests; fabricated or omitted digests are not valid provenance.

For an explicitly labeled smoke test only, `--allow-unmanifested` permits missing manifest hashes. It does not forgive missing cells, evaluator errors, wrong metadata, or incomplete episode counts.

Outputs:
- `per-task.tsv`: one row per official task/mode cell.
- `summary.tsv`: pooled and task-macro results per run/mode.
- `audit.tsv`: coverage, metadata, provenance and pairing status.

## Statistical limits

Wilson intervals follow the per-cell native success-rate convention. The task-macro mean is an extra descriptive metric; it is not substituted for the native TAVIS pooled average. The tool intentionally does not compute paired confidence intervals unless both the stable episode IDs and seed keys exist in every matched task/mode cell and match across runs. GALT remains a secondary process metric: it must not replace task success.

## Scope

This is a postprocessor for results that have already been generated by the official benchmark. It does not imply that a TAVIS rollout, checkpoint reproduction, or SOTA comparison has been executed.
