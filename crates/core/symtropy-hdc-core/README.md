# symtropy-hdc-core

Deterministic, permissively licensed hyperdimensional-computing primitives for
Symtropy and independent research projects.

The crate deliberately contains no physics or cognition policy. It provides:

- dense continuous and bipolar hypervectors;
- deterministic item memory without a runtime RNG dependency;
- role/value binding, bundling, permutation, and cosine similarity;
- locality-preserving scalar level encodings;
- versioned encoder specifications and stable fingerprints.

HDC representations are semantic indexes and memories. They are not a
replacement for authoritative numerical state, cryptographic hashes, or the
physics solver.
