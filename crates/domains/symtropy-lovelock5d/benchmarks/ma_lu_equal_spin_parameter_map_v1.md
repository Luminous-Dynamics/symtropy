# Ma–Lü equal-spin Myers–Perry parameter map — JHEP version of record

**Source pin:** Ma and Lü, *Quadratic curvature correction to 5D Myers–Perry metric*, JHEP 05 (2026) 081, DOI 10.1007/JHEP05(2026)081, published 8 May 2026. This note uses the publisher's version of record, not an arXiv-v1 text extraction.

Eq. (2.9) defines
\[
\chi_a=\frac{a}{\sqrt{\mu}},\qquad \chi_b=\frac{b}{\sqrt{\mu}}.
\]
For equal spins, set \(q=a/r_h\). The 5D MP horizon equation and angular velocity give
\[
\frac{\mu}{r_h^2}=\frac{(1+q^2)^2}{2},\qquad
\nu_h=\Omega_H r_h=\frac{q}{1+q^2}.
\]
Consequently,
\[
\chi=\frac{a}{\sqrt{\mu}}=\frac{\sqrt2\,q}{1+q^2}
=\sqrt2\,\nu_h
\]
**exactly**, while the inverse subextremal branch is
\[
q=\frac{1-\sqrt{1-4\nu_h^2}}{2\nu_h}
=\nu_h+\nu_h^3+2\nu_h^5+5\nu_h^7+14\nu_h^9+42\nu_h^{11}
+O(\nu_h^{13}).
\]

As an independent check, the equal-spin specialization of Eq. (3.9) is
\[
\frac{\mu}{r_h^2}
=\frac12+\frac{\chi^2}{2}+\frac{5\chi^4}{8}
+\frac{7\chi^6}{8}+O(\chi^8),
\]
which follows by substituting the inverse \(\chi\)-series into the exact horizon relation.

The first-coupling source normalization against Symtropy remains
\[
\alpha_R=\frac{\alpha_{GB}}{4}
\]
on the Ricci-flat MP background only. It is not a finite-coupling equivalence on generic metrics.

**Claim ceiling:** exact equal-spin MP kinematics, Eq. (3.9) through \(\chi^6\), and first-coupling source normalization. No corrected metric or finite-coupling branch is implied.
