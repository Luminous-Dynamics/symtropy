# SEL-07D2 Exact Causal Randomization Test V1

## Governing theorem

`descriptive Fisher reference != causal randomization test unless a qualified assignment mechanism generates the causal reference law`.

SEL-07D2 is the first layer allowed to emit a causal randomization probability. It consumes the qualified executable assignment reference from SEL-07D1 rather than relabeling the descriptive SEL-07B2 probability.

## Required current capabilities

Execution requires all three current non-Serde capabilities:

- `ValidatedSelectionAnalysisFrame<'_>`;
- `ValidatedCausalSelectionEffect<'_>`;
- `ValidatedCompleteRandomizationReference<'_>`.

The frame, C2 effect and D1 assignment reference must bind the exact same frame and C1 identification lineage. Their denominators and Reference/Comparison assignment counts must agree.

A raw B2 association, a B2 p-value, a C1 design label, a raw C1/D1 digest, or a serialized C2 effect is insufficient.

## V1 sharp null

V1 tests exactly:

`CausalSharpNull::NoIndividualAssignmentEffectOnViability`.

Under this sharp null, every individual's observed viability outcome is held fixed while the D1-qualified complete-randomization assignment law is enumerated.

This is a sharp individual-level assignment null. It is not automatically an average-treatment-effect null, confidence interval, equivalence test, or heterogeneous-effects model.

## V1 statistic

V1 has one statistic only:

`Comparison - Reference` viability-window death-risk difference.

There is no runtime statistic selector.

The observed statistic is recomputed from:

- the exact current B1 viability outcomes;
- the exact realized D1 assignment vector.

It must equal the current C2 causal viability-risk point effect exactly. A mismatch fails closed.

## Exact assignment enumeration

D2 enumerates every assignment vector permitted by the current D1 `CompleteFixedComparisonCount` support.

For each assignment:

1. keep all individual viability outcomes fixed under the sharp null;
2. assign exactly the D1 Comparison count;
3. compute the exact reduced Comparison-minus-Reference death-risk difference;
4. add the statistic to the exact multiplicity distribution;
5. classify it under the frozen two-sided ordering rule.

Enumeration is over canonical D1 assignment-unit order. Input row order is already non-semantic because B1/D1 current authority requires canonical persistent-individual ordering.

## No approximation under the exact type

D1 can describe complete-randomization supports much larger than D2 should exhaustively enumerate.

D2 V1 therefore has an explicit bound:

`CAUSAL_RANDOMIZATION_MAX_ASSIGNMENTS = 100_000`.

If the D1 support exceeds this bound, D2 returns `ExactEnumerationSupportTooLarge`.

It does **not** silently switch to:

- Monte Carlo randomization;
- asymptotic normal approximation;
- chi-square approximation;
- saddlepoint approximation;
- truncated support;
- importance sampling.

Any approximate or sampled randomization procedure must have a separate type, method authority, error contract and qualification theorem.

## Frozen two-sided ordering

V1 uses exactly:

`CausalTwoSidedOrdering::AbsoluteStatisticAtLeastObserved`.

An assignment is in the two-sided tail when:

`|RD_assignment| >= |RD_observed|`.

All comparisons are exact rational cross-products; no floating point is used.

## Complete statistic distribution

V1 persists the exact statistic distribution as canonical `(statistic, multiplicity)` entries rather than storing every assignment vector in the D2 result.

The full assignment law remains represented by D1. D2's distribution is a deterministic reduction of exhaustive D1 enumeration under the sharp null.

Local validation requires:

- nonempty canonical distribution;
- every statistic in reduced canonical form;
- positive multiplicities;
- multiplicities summing to exact support size;
- observed statistic present in the distribution;
- tail multiplicities recomputing the stored extreme count;
- exact reduced probability recomputing from `extreme/support`.

Current replay is still required to prove that this locally consistent distribution is the one generated by the current D1/frame/C2 authorities.

## Hand-checkable 2-vs-2 theorem

The public fixture has fixed outcomes:

```text
individual-a: survived
individual-b: survived
individual-c: died
individual-d: died
```

and realized complete randomization:

```text
Reference:  a, b
Comparison: c, d
```

D1 establishes six permitted assignments because `C(4,2)=6`.

Holding outcomes fixed and enumerating those six assignments produces:

```text
risk difference -1 : 1 assignment
risk difference  0 : 4 assignments
risk difference +1 : 1 assignment
```

The observed statistic is `+1`. Under absolute-magnitude two-sided ordering, two assignments are at least as extreme:

`2 / 6 = 1 / 3`.

This is a causal randomization probability because its reference law comes from current D1 assignment authority.

## Relationship to B2 Fisher-style reference

For the same 2-vs-2 fixture, B2's descriptive fixed-margin Fisher-style probability-ordering reference also evaluates numerically to `1/3`.

D2 explicitly tests that numerical equality.

But the evidence objects are not equivalent:

- B2 is bound to the descriptive validated analysis frame and its built-in fixed-margin reference calculation;
- D2 is additionally bound to C1 causal identification, D1 qualified assignment materialization/exchangeability and C2 causal-effect lineage;
- B2 and D2 use separately specified two-sided ordering theorems.

Therefore:

`same numeric probability != same evidentiary meaning`.

D2 does not copy B2's p-value.

The two ordering rules are not claimed to be generally identical. Their equality in the public fixture is a proved fixture-specific numerical result, not a universal theorem.

## Group-label reversal

Swapping Reference and Comparison reverses the sign of the observed exact statistic while the absolute-magnitude two-sided probability remains unchanged for the symmetric public fixture.

The evidence identity still changes because the frame, C2 effect and D1 realized assignment identities change.

## Qualification-sensitive identity

Changing only D1's assignment-materialization qualification authority can preserve:

- the realized assignment vector;
- support size;
- observed point effect;
- exact D2 randomization probability.

It must still change D1 and D2 evidence identity.

This preserves the distinction between numerical result and causal authority provenance.

## Persisted result versus current authority

`CausalRandomizationTestResult` is serializable and has deterministic representation identity.

`ValidatedCausalRandomizationTest<'_>` is non-Serde and is reconstructed only by rerunning D2 against current:

- validated frame;
- validated C2 causal effect;
- validated D1 randomization reference.

Exact equality is required.

Thus:

`locally self-consistent randomization result != current causal-randomization authority`.

## Adversarial corpus

`causal_randomization_test_v1` establishes at least:

1. exact six-assignment enumeration in the 2-vs-2 fixture;
2. exact distribution `{-1×1, 0×4, +1×1}`;
3. exact two-sided randomization probability `1/3`;
4. Serde-restored result requires current replay;
5. D2 `1/3` may equal B2 `1/3` while D2 binds D1/C1/C2 causal lineage;
6. group-label reversal reverses observed statistic while preserving the two-sided probability in the symmetric fixture;
7. D1 materialization-qualification-only drift changes D2 evidence identity without changing the probability;
8. altered serialized probability fails local validation before current replay;
9. exact-enumeration ceiling is explicit and no approximation mode exists in V1;
10. wire shape names `sharp_null` and excludes downstream selection/fitness/adaptation/speciation promotion.

## Explicit non-claims

SEL-07D2 establishes only an exact causal randomization test for one sharp null under one qualified complete-randomization assignment law.

It does not establish:

- a causal confidence interval;
- a confidence set obtained by test inversion;
- average treatment-effect heterogeneity;
- per-protocol/complier effects;
- generic or lifetime fitness;
- a population-genetic selection coefficient;
- universal beneficial/deleterious mutation status;
- adaptation;
- reproductive isolation;
- speciation.

A small D2 probability is not, by itself, adaptation evidence or a selection coefficient.
