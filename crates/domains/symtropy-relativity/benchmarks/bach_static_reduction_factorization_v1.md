# Exact factorization and parameter kernel of the static Bach equations

**Status:** symbolic derivation cross-checked; Rust factorized oracle authored, not compiled.
**Owner:** [BH-STATIC-ODE-FACTOR-001 #6054](https://github.com/Luminous-Dynamics/symtropy/issues/6054).
**Related:** [PR #5968](https://github.com/Luminous-Dynamics/symtropy/pull/5968), [Lean BVP adapter #6019](https://github.com/Luminous-Dynamics/symtropy/issues/6019), [matched SOTA benchmark #6043](https://github.com/Luminous-Dynamics/symtropy/issues/6043).

## 1. Factor the generic first combination

For
[
ds^2=-B(r)dt^2+B(r)^{-1}dr^2+r^2d\Omega^2,
]
Mantica–Molinari's static reduction defines
[
A=\frac{1-B}{r^2}+\frac{B''}{2},\quad
E=\frac12\left(\frac{1-B}{r^2}+\frac{B'}r-\frac{B''}{2}\right),\quad
X=A'+\frac Ar.
]
The first scalar equation is
[
B_1+B_2=-\frac{2B}{r}X-\frac{2B}{3}X'.
]

A generic-function symbolic derivation—not a four-term substitution—gives the exact factorization
[
\boxed{B_1+B_2=-\frac{B(r)}{3r}\left(rB''''(r)+4B'''(r)\right).}
]

On a static annulus with (r>0) and (B(r)>0), the first vacuum equation is therefore equivalent to
[
rB''''+4B'''=0
\iff (r^4B''')'=0.
]
Integrating gives
[
B'''=K r^{-4},\
B''=C_2-\frac{K}{3r^3},\
B'=C_2r+C_1+\frac{K}{6r^2},\
\boxed{B(r)=\frac{c_{-1}}r+c_0+c_1r+c_2r^2.}
]
This is the complete local solution of the first reduced equation on the declared static domain.

The factorization is useful because it exposes a linear differential operator hidden inside the nonlinear-looking scalar expression. It is not a generic four-dimensional Bach identity: it relies on the static spherical ansatz and the nonzero static lapse.

## 2. The second equation becomes algebraic

Substituting the four-term solution into the independent difference equation yields
[
\boxed{B_1-B_2=\frac{4Q}{3r^4},\quad
Q=c_0^2-3c_1c_{-1}-1.}
]
Hence the complete static vacuum family is the four-term solution with one algebraic constraint (Q=0), leaving three independent parameters. The quadratic coefficient (c_2) remains unconstrained by Q.

The two scalar equations must stay distinct:
- (B_1+B_2) eliminates all non-four-term profiles;
- (B_1-B_2) applies the algebraic constraint to the remaining family.

In particular, changing (c_0) off shell leaves the first factorized equation zero but makes the second nonzero. This is an excellent negative control because it catches implementations that accidentally check only one scalar equation.

## 3. Fréchet kernel at the frozen Mannheim–Kazanas point

Use
[
(c_{-1},c_0,c_1,c_2)=(-17/10,7/10,1/10,-1/100).
]
For a perturbation within the four-term family,
[
h(r)=\frac{\delta c_{-1}}r+\delta c_0+\delta c_1r+\delta c_2r^2,
]
the linearized algebraic constraint is
[
14\delta c_0-3\delta c_{-1}+51\delta c_1=0.
]
The three independent tangent directions are
[
v_{-1}=(1,3/14,0,0),\quad
v_1=(0,-51/14,1,0),\quad
v_2=(0,0,0,1),
]
in coefficient order ((\delta c_{-1},\delta c_0,\delta c_1,\delta c_2)). Their profile perturbations are
[
h_{-1}(r)=1/r+3/14,\quad
h_1(r)=r-51/14,\quad
h_2(r)=r^2.
]
They span the three-dimensional kernel of the linearized pair of static reduced equations: the first equation's fourth-order linear operator admits the four-term perturbations, and the second equation removes one direction through the tangent constraint.

The linearized first scalar equation for a general perturbation h around an on-shell background B0 is
[
D(B_1+B_2)[B_0](h)
=-\frac{B_0}{3r}\left(rh''''+4h'''ight),
]
because the background factor (rB_0''''+4B_0'''=0). On the four-term kernel, the second linearized equation is
[
D(B_1-B_2)[B_0](h)
=\frac{4}{3r^4}
(2c_0\delta c_0-3c_1\delta c_{-1}-3c_{-1}\delta c_1).
]

Consequently, an approximate inverse that does not handle these three parameter directions is singular. A radii-polynomial construction must either:
- augment the unknowns with the three continuation parameters and add a phase condition; or
- explicitly select a physically justified transverse slice by fixing three independent solution parameters.

Do not call parameter-fixing a gauge symmetry unless it is generated by an actual gauge transformation. Areal-radius gauge and the time normalization must be handled separately and explicitly.

## 4. Consequence for the formal-certification programme

The exact MK family is a known-answer/control problem, not a difficult generic nonlinear-discovery problem. Keep it in #6019 as plumbing for:
- Chebyshev series and exact tail enclosures;
- component and reduced-equation agreement;
- source/toolchain/Lean theorem replay;
- parameter-kernel detection and constrained inverse plumbing.

The first meaningful radii-polynomial discovery target should be a genuinely deformed static theory with independently specified fields/operators, or a stationary axisymmetric rotating problem. That problem must have its own action, boundary/gauge contract and operator-domain proof.

## 5. New Rust oracle

PR #5968 adds `static_spherical_bach_sum_factorized(radius, lapse_jet)`, which evaluates the factored first scalar equation directly from (B,B''',B''''). It is an independent reduced-equation check against the full-component projection assembled by `static_spherical_bach`.

Authored tests:
- compare the factorized sum against the full-component projection for several generic degree-five lapses;
- require the factorized sum to vanish for both on-shell and off-shell four-term profiles;
- retain the existing off-shell difference residual (4Q/(3r^4)), which must remain nonzero when Q is mutated.

These Rust tests are authored but not executed in this environment.

## 6. Claim ceiling

The factorization and solution-family classification apply to the four-dimensional pure Weyl-squared vacuum equations under the static, spherically symmetric ansatz on a domain with (r>0) and (B(r)>0). They do not classify rotating, nonspherical, matter-coupled, scalar-extended or generic higher-curvature solutions. The three-dimensional kernel is the tangent to the exact static solution family, not a statement that all three directions are gauge.
