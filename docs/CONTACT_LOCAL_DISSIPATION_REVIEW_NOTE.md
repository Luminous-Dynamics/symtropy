# Contact-local dissipation review note

During the #777 thermodynamic-ledger audit, the current physics callback path was found to report contact-friction dissipation through a body-agnostic scalar callback. `ConsciousnessField::record_dissipation` then distributes that heat equally across every registered entity.

This means friction generated by one contact can currently alter the thermal state of unrelated distant agents.

This note intentionally does **not** patch that behavior inside the EnergyBudget invariant tranche. The clean follow-up should preserve source compatibility while making the contact participants explicit, for example with a typed/body-attributed callback or an equivalent physics-boundary adapter whose tests prove:

- contact A/B friction heat reaches only registered A/B participants;
- unrelated entity C receives no temperature/entropy mutation;
- one registered participant receives only the declared local share/policy;
- ledger dissipation is recorded exactly once;
- collision reservoir drain and friction heat are not double-counted;
- non-contact dissipation remains distinguishable from contact-local dissipation.

Until that follow-up and #777's control-volume theorem are qualified, the current thermodynamic ledger must not be presented as a full physical-conservation proof.
