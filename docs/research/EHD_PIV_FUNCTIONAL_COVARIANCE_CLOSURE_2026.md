# EHD-PIV-UQ-011 — joint functional covariance closure

**Status:** reference implementation authored; Rust format/build/tests/Clippy pending.  
**Issue:** #7005.  
**Parent:** UQ-005 / PR #6899, with covariance-family and input-evidence work in UQ-007–UQ-010.

## 1. Why validate the full matrix?

UQ-005 propagates a supplied field covariance model into the four integrated quantities:

`q = [\dot m, \Pi_x, \Pi_y, \Pi_z]^T`

and returns a 4×4 covariance matrix `Σ_q`.

The matrix is the joint uncertainty object. Checking only its four diagonal variances is insufficient: a symmetric matrix can have four positive diagonal entries and still have a negative eigenvalue. In that case some linear combination of the declared functionals has negative variance, which is mathematically impossible for a covariance matrix.

The base reducer sums:
- per-sample 3×3 local velocity covariance contributions;
- explicitly declared shared latent-mode outer products.

The spatial extension then adds the cross-location covariance contribution generated by the validated spatial kernel. Each input contribution should be PSD; their complete sum should also be PSD. Validate the final output, not only each component.

## 2. Unit scaling matters

The four functionals do not share units: mass flow is kg/s while momentum-flux components are N. A raw absolute eigenvalue tolerance applied directly to the dimensional 4×4 matrix is not unit invariant.

The implementation therefore:
1. Checks finiteness.
2. Rejects negative marginal variances.
3. Checks symmetry using a scale-aware tolerance relative to the geometric mean of the paired marginal variances and observed off-diagonal values.
4. Handles exact zero-variance rows explicitly: a zero-variance functional cannot have nonzero covariance with another functional.
5. Standardizes positive-variance variables to a dimensionless correlation matrix.
6. Uses fixed-size Jacobi rotations to estimate the minimum eigenvalue.
7. Rejects eigenvalues below the predeclared dimensionless tolerance.

The proposed initial tolerances are:
- symmetry: relative (10^{-10});
- Jacobi off-diagonal convergence: (10^{-14});
- final minimum correlation-matrix eigenvalue: no lower than (-10^{-10}).

These are numerical implementation tolerances, not metrology uncertainty thresholds or a substitute for a condition-number study.

The output covariance is not silently symmetrized or projected onto the PSD cone. A symmetric average is used only after the original entries have passed the explicit symmetry check, to form the matrix on which the eigensolver operates; the returned covariance retains the original computed entries.

## 3. Integration boundary

The base functional reducer validates its complete 4×4 covariance after local and shared-mode contributions have been accumulated.

The spatial PIV reducer calls the same validator again after adding the full cross-location covariance contribution. This is important because the spatial path is the final consumer-facing joint covariance and must not rely only on the base reducer's validation.

The gate establishes mathematical covariance structure only. It does not prove:
- that each supplied local covariance is empirically calibrated;
- that shared latent-mode sensitivities are physically correct or mutually independent;
- that the spatial kernel is authenticated or appropriate to the actual protocol;
- that the PIV/reference residual covariance is PIV-only error;
- that pressure, viscous traction, storage, body forces or a complete control-volume balance are included.

## 4. Manufactured negative controls

The six authored new tests include (including a mixed-unit scale-invariance case with independent scale factors spanning 1e-12 to 1e18):
- rank-deficient PSD matrices;
- a roundoff-scale negative eigenvalue just within the tolerance;
- an indefinite symmetric matrix with all four diagonal entries positive;
- material matrix asymmetry;
- a zero-variance functional with a nonzero cross-covariance;
- invariance of the PSD disposition under independent rescaling of the mass-flow and momentum-flux units.

The full existing propagation tests continue to exercise local covariance, shared modes, and spatial cross-location contributions.

## 5. Validation status

The authoring environment has no Cargo/rustc/rustfmt, so formatting, compilation, execution and Clippy have not been claimed. The exact-head hosted CI is the next executable check.

No physical PIV cohort, empirical covariance fit, integrated mass-flow benchmark, EHD force balance or thrust measurement is claimed by this software invariant.

## 6. Follow-on numerical validation

Before treating these tolerances as settled, run:
- random PSD matrices spanning many orders of magnitude and condition numbers;
- rank-deficient matrices with exact and near-zero variances;
- matrices generated as sums of random (B B^T) factors and compared to a high-precision or independent eigenvalue oracle;
- near-boundary matrices with controlled negative eigenvalues;
- unit-rescaling tests (e.g. convert mass-flow units and momentum units independently) to confirm invariant acceptance/rejection.

The validator is deliberately fixed-size and has constant computational cost; it should be negligible compared with the current O(N²) spatial covariance propagation.
