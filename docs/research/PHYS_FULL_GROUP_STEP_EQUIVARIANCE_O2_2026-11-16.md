# Discrete O(2) step-map equivariance reference v0.1

This is the first physical receiver-side slice of [PHYS-FULL-GROUP-STEP-EQUIV-001 #4940](https://github.com/Luminous-Dynamics/symtropy/issues/4940), built on the constrained planar dumbbell pHDAE step reference in [#3120](https://github.com/Luminous-Dynamics/symtropy/pull/3120).

## Why this test is different

A continuous equation can be equivariant while a concrete discrete update is not. This reference tests the actual one-step map:

    Phi_g(step_dt(x, u)) ~= step_dt(Phi_g(x), Phi_g(u))

It does not infer discrete-map symmetry from generator closure alone.

## Split group fixture

The target full group is O(2), written as the split extension:

    O(2) = SO(2) ⋊ C2

The identity-connected subgroup is generated by

    J = [[0, -1],
         [1,  0]]

and the disconnected reflection component is

    F = [[1,  0],
         [0, -1]]

with the defining adjoint relation

    F J F^-1 = -J

The finite component action therefore reverses the orientation of the connected rotation generator. This sign is physically visible in the 2D angular momentum, which is a pseudoscalar: it changes sign under reflection.

The state action for a full O(2) element is represented as R(theta) F^epsilon, where epsilon is 0 or 1. Positions, velocities and applied force covectors are transformed by the same orthogonal matrix for this Euclidean mass metric. Linear momentum transforms as a vector; angular momentum transforms with det(R(theta)F^epsilon).

## What the executable test checks

The Rust tests in `tools/phdae-dumbbell-reference/constrained_dumbbell.rs` now include:

- direct matrix evaluation of the disconnected adjoint relation F J F^-1 = -J;
- the group relation F R(theta) F = R(-theta);
- energy and linear-momentum covariance under reflection;
- the angular-momentum pseudoscalar sign change;
- actual constrained dumbbell step-map commutation for 32 deterministic angles, with both connected and reflected components;
- scalar constraint multiplier invariance;
- external-work and constraint-reaction-work consistency;
- a wrong-force-transformation negative control that must break step equivariance.

The solver itself is not modified. This is an independent qualification layer around the existing frozen pHDAE step implementation.

## Evidence boundary

The angle sweep is a deterministic numerical test corpus, not a formal proof for every real angle. The exact finite-component and matrix-conjugation identities are separately exercised on the frozen O(2) representation. The pHDAE step result remains floating-point and solver-profile dependent.

This v0.1 does not claim arbitrary-time trajectory equivalence, all possible initial states, nonlinear manifold global invariance, unilateral contact/friction, 3D O(3), or arbitrary non-split Lie-group extensions. It creates no scientific-search pruning authority. Full physical evidence still requires metric, force/momentum duality, constraints, observables, and the independent receiver-side contract in [#4781](https://github.com/Luminous-Dynamics/symtropy/issues/4781).
