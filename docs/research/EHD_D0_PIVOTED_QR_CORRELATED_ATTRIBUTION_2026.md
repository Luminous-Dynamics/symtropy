# D0-QR-001 — correlated source attribution with pivoted QR and full covariance

**Status:** manufactured Rust kernel and seven tests authored; Rust execution and exact-head CI pending  
**Parent:** EHD-DISC-001 / #6681 and D0-001 / #6758

## Why this increment

The initial D0 reference used four mutually orthogonal source signatures. That was useful for a first manufactured error-attribution test, but it is not enough for real metrology and model discrepancy: parameter effects, numerical bias, thermal drift, cable force and omitted physics can have correlated signatures.

The next reference supports correlated but identifiable source signatures. It uses full observation covariance, column-pivoted modified Gram–Schmidt QR, explicit rank rejection and a bounded condition proxy.

This is still a manufactured solver-independent attribution oracle, not an EHD calibration model.

## Model

For an eight-component residual and four source families:

\[
r=A\beta+\epsilon,\qquad \epsilon\sim\mathcal N(0,\Sigma).
\]

The kernel Cholesky-factorizes \(\Sigma=LL^\mathsf T\) and solves \(L\tilde r=r\), \(L\tilde A=A\). It does not form \(\Sigma^{-1}\), silently symmetrize covariance or add diagonal jitter.

For the whitened source matrix:

\[
\tilde A\Pi=QR,
\qquad
R\hat\beta_\Pi=Q^\mathsf T\tilde r.
\]

The column permutation \(\Pi\) is restored before returning coefficients in the original source order. A rank-deficient basis is rejected. A near-confounded but full-rank basis is rejected when the pivoted-QR diagonal condition proxy \(\max |R_{ii}|/\min |R_{ii}|\) exceeds \(10^8\). This is explicitly a proxy, not a spectral condition number.

The unexplained residual is measured in whitened coordinates, so its L2 norm is a Mahalanobis residual norm. The measurement-noise bound must be supplied in the same metric.

## Manufactured reference

Four source signatures are generated by mixing the original Hadamard basis. They are correlated but independent. The observation covariance is AR(1) with \(\rho=0.25\).

Injected coefficients:

| Error source | Coefficient |
|---|---:|
| Parameter perturbation | 1.50 |
| Numerical bias | -0.75 |
| Measurement artifact | 0.50 |
| Model-form discrepancy | 2.00 |

Independent numerical recomputation recovers all four coefficients and gives a QR diagonal condition proxy of approximately 1.5236674. The whitened unexplained residual is at floating-point zero for this no-noise manufactured case.

## Adversarial controls

- Exact source confounding: duplicate columns → RankDeficientSignatureBasis.
- Near confounding: one source equals another plus \(10^{-9}\) of its original signature → condition proxy about \(1.28\times10^9\), rejected.
- Asymmetric covariance → reject; do not symmetrize.
- Non-positive-definite covariance → reject; do not add jitter.
- Failed independent conservation ledger → PhysicalLedgerFailure, even when all residual source coefficients are recovered.
- Unexplained whitened residual above the declared noise bound → NotEvaluable.

The conservation gate and validation-envelope state remain externally supplied. A discrepancy fit cannot edit them.

## Claim boundaries

This reference does not estimate a real covariance matrix, perform profile likelihood, fit a nonlinear discrepancy process, validate an EHD instrument or produce calibrated predictive intervals. The QR condition proxy is only a cheap guard; general production use should add a high-quality SVD-based condition report and compare it with the QR path on frozen matrices.
