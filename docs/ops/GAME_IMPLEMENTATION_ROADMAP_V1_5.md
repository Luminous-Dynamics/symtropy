# Symtropy Game Implementation Roadmap

## Strategy

Do not build a large companion roster first.

```text
preserve Firstlight / Nine Pumps causal spine
→ prove three deep professions and one operating district
→ add six flagship companion life anchors
→ prove requests, refusals, and two joint procedures
→ prove households, independent projects, and absence
→ add optional secret-history framework
→ run emotional recall and agency studies
→ expand cast only after evidence
```

# Gate 0 — Existing Dependencies

Required:

- authoritative world state;
- stable agent and asset IDs;
- NPC perception and belief separation;
- profession competence and schedules;
- household and relationship state;
- IRIS privacy boundary;
- save/load, replay, and worldline ancestry.

# Gate 1 — Life Anchors

Implement Sera, Tomas, Amadi, Morrow-7, Nia, and Mara with:

- home or embodied place;
- profession;
- schedule;
- household or protected relationships;
- one independent project;
- one refusal boundary;
- ordinary habits;
- absence behavior.

**Proof:** each remains recognizable in a week with no travel content.

# Gate 2 — Requests and Refusal

Implement request, counterproposal, defer, evidence request, and refusal.

**Proof:** at least one companion refuses a useful but unsafe or illegitimate action and survives doing so.

# Gate 3 — Two Joint Procedures

Prototype:

- energized repair with Tomas or Sera;
- evacuation and transport with Nia or Amadi.

**Proof:** roles, tools, authority, synchronization, interruption, and evidence remain authoritative.

# Gate 4 — Practiced Coordination

Record reviewed runs, shorthand, accommodations, and challenge points.

**Proof:** repeated coordination reduces communication burden without producing global stat bonuses.

# Gate 5 — Independent Life

Implement household, work, care, project, career, and availability packets.

**Proof:** six-month absence produces causal change and no named-companion freeze.

# Gate 6 — IRIS Boundary

Expose shared procedures, permissions, and observable behavior while redacting private cognition.

**Proof:** privacy red-team cannot recover attraction, undisclosed fear, medical information, or private memories.

# Gate 7 — Departure and Restoration

Implement leave, withdrawal, migration, death, disputed restoration, and fork reconciliation.

**Proof:** no restored continuity resumes office, intimacy, or travel automatically.

# Gate 8 — Secrets

Implement optional secret records, discovery predicates, branch provenance, and non-loot rewards.

**Proof:** one secret requires repeated place familiarity, one depends on shared history, and one remains unresolved.

# Gate 9 — Emotional Continuity Benchmark

Run thirty days, three absences, and three worldline branches.

Promotion requires:

- deterministic replay;
- save migration;
- performance traces;
- agency study;
- delayed emotional recall;
- privacy and accessibility review;
- failure and ablation logs.

# Gate 10 — Expansion Decision

Only after Gate 9 decide whether to:

- expand the Firstlight cast;
- add romance for eligible adult relationships;
- add machine and alien companions;
- generalize companion procedures to vehicles, expeditions, governance, and first contact.

A failed benchmark should shrink or revise the system rather than trigger more content production.
