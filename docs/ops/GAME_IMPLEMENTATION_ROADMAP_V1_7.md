# Symtropy Game Implementation Roadmap

## Strategy

Do not build a procedural galaxy or visual gate first.

Preserve the existing Firstlight and South Cut proof sequence. Add one deterministic chronology harness, one seed vessel, two asynchronous regions, one Atlas route, and one emergency.

# Gate A — Existing Regional Proof

Required before interstellar implementation claims:

- authoritative resource and body state;
- named NPC continuity;
- professions and shifts;
- companion refusal;
- settlement services and succession;
- Chronicle replay;
- host-safe authority.

**Exit:** representative regional systems are integrated or explicitly mocked as dependencies.

# Gate B — Atlas Time and Event Ancestry

Implement fixed-point Atlas Time, causal events, region frontiers, and snapshot roots.

**Exit:** deterministic replay and monotonic ordering.

# Gate C — Proper and Knowledge Time

Implement one relativistic trajectory and one delayed remote observation.

**Exit:** player UI distinguishes Atlas, civic, proper, and knowledge time.

# Gate D — Seed Vessel Slice

Implement Muni Seventeen at reduced population scale first:

- twelve named residents;
- four households;
- six professions;
- one child life-course;
- one companion refusal;
- one mission-amendment vote;
- one quiet multi-year passage.

**Exit:** voyage history remains coherent without forced crisis.

# Gate E — Asynchronous Regions

Advance origin and vessel independently.

**Exit:** no early knowledge, duplicate player, or host-owned time.

# Gate F — Metric Trim and Sail

Implement bounded vehicle metric trim and one sublight sail mission.

**Exit:** propulsion, braking, power, heat, and proper time remain conserved.

# Gate G — Far Station Arrival

Implement destination survey, prior ecological claim, settlement founding, and local sovereignty.

**Exit:** player cannot place the Anchor before a functioning receiving society exists.

# Gate H — Anchor Components

Implement clocks, survey, lattice, power, cooling, authority, quarantine, and approach volume.

**Exit:** missing component blocks route certification through legible reason.

# Gate I — Route Graph and Chronology Protection

Implement directed route edges and nonpositive-cycle rejection.

**Exit:** adversarial route fixture is rejected deterministically.

# Gate J — Pairing Protocol

Implement field echo, information pulse, instrument, mass standard, probe, cargo, and crew certification.

**Exit:** evidence accumulates by stage and survives replay.

# Gate K — Unique Transit

Implement reservation, manifest freeze, commit, route custody, positive latency, and arrival reconciliation.

**Exit:** process crash creates no duplicate or missing unique asset.

# Gate L — Multiplayer Future Migration

Player A undertakes seed voyage while Player B remains at origin.

**Exit:** later reconnection is causal and host migration preserves state.

# Gate M — Route Emergency

Implement cooling fault, reduced capacity, worker refusal, committed-transit recovery, rescue triage, and scar.

**Exit:** emergency produces traced consequences and five-year persistence.

# Gate N — Three Reconnection Outcomes

Prove:

- public route;
- seasonal limited route;
- legitimate refusal.

**Exit:** refusal remains a complete game state rather than failed progression.

# Gate O — Full Benchmark and Research

Run performance, comprehension, emotional recall, accessibility, multiplayer, safety, and replay studies.

**Exit:** evidence bundle complete.

# Expansion Decision

Only after Gate O decide whether to add:

- more seed worlds;
- larger route graphs;
- route cities;
- alien metric interfaces;
- military fleets;
- moving anchors;
- generated systems;
- galactic economy.

# Cut Order

Preserve:

1. chronology;
2. knowledge delay;
3. seed voyage;
4. destination sovereignty;
5. unique transit;
6. multiplayer location;
7. route failure.

Cut:

- procedural galaxy;
- many endpoint visuals;
- free personal FTL;
- instant route construction;
- broad fleet warfare;
- hundreds of destinations;
- cinematic route sequences.

# Production Maxim

> **Reach one star honestly before promising the galaxy.**
