# Symtropy Game Implementation Roadmap

## Strategy

Replace the forty-hour content target with a harder sequence of smaller proofs.

First prove ten enjoyable minutes. Then prove one inhabited half-hour. Then prove unique cast coherence, causal catastrophe state, constrained evacuation, and one mobile-base route. Only afterward expand toward forty hours.

# Gate A — Empty Greybox Feel

Implement movement, camera, carry, climbing, one tool, one vehicle cab, sound, and accessibility controls without narrative content.

**Exit:** players enjoy moving and manipulating objects in an empty test space.

# Gate B — Bent Feeder Ten Minutes

Implement one physical fault, one human need, two approaches, bounded IRIS assistance, persistent state, and replay capture.

**Exit:** players understand and remember what they physically did.

# Gate C — Thirty-Minute Firstlight

Implement approach, signature wonder, ordinary-life hub, two generated residents, personal modification, and crawler exterior.

**Exit:** players remember two people, one place, and one self-directed desire.

# Gate D — Unique Cast Core

Implement role anchors, twelve fixed cast seeds, households, voices, first-image scenes, ledger persistence, and multiplayer agreement.

**Exit:** casts remain coherent and distinguishable without universal named residents.

# Gate E — Emergent Practice

Implement maintenance, care, witness, mobility, and cultural interest observation without class selection.

**Exit:** players understand why opportunities followed their actions.

# Gate F — Warning and Preparation

Implement observer-bound warnings, anomaly prototype, institutional disagreement, and several preparation effects.

**Exit:** players make choices under uncertainty without being told the final disaster is guaranteed.

# Gate G — Catastrophe State

Implement coupled escalation, threshold evidence, operational cells, dynamic route graph, survivor groups, and post-departure Firstlight simulation.

**Exit:** fixed seeds replay exactly and varied actions alter outcomes.

# Gate H — Breaking Gameplay

Implement route, care, continuity, household, threat, and crawler fronts with independent NPC action and refusal.

**Exit:** players perceive agency without expecting a perfect rescue.

# Gate I — Crawler Physics

Implement component graph, mass distribution, handling, power, water, cargo, residents, damage, repair, and route compatibility.

**Exit:** two load plans feel and operate differently.

# Gate J — Loading and Departure

Implement physical capacity, custody, survivor opinions, route collapse, title reveal, first horizon, and post-title ordinary life.

**Exit:** the crawler feels inherited from Firstlight rather than awarded.

# Gate K — Two-Hour Benchmark

Run moderated, unmoderated, accessibility, multiplayer, ablation, and delayed-recall studies across twelve seeds.

**Exit:** benchmark promotion gates pass.

# Gate L — First Five Post-Title Hours

Only after Gate K, implement:

- stabilization;
- first camp;
- first external settlement;
- one convoy encounter;
- one professional follow-up;
- one survivor departure;
- one clue about the Breaking;
- first meaningful base modification.

**Exit:** players form self-directed route, home, profession, and relationship goals.

# Deferred Until Proof

- broad planetary generation;
- additional catastrophe families;
- many mobile-base chassis;
- full convoy civilization;
- spacecraft conversion;
- Atlas implementation;
- large alien content expansion;
- forty-hour authored campaign volume.

# Kill Rules

- Cut content before compromising movement or interaction feel.
- Reduce cast scope before accepting incoherent generated people.
- Use an authored cast fallback before shipping procedural mush.
- Cut catastrophe fronts before making all choices cosmetic.
- Cut module count before hiding mass and dependency consequences.
- Stop production expansion if players do not remember people after seven days.

## Roadmap Maxim

> **The route to the stars begins only after the game proves that players want to keep driving one damaged vehicle away from one place they genuinely remember.**
