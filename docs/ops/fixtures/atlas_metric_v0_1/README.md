# Atlas Metric v0.1 Fixtures

This directory contains design-stage schemas and a representative fixture for the v2.4 Atlas benchmark.

They are not evidence of implementation.

Files:

- `atlas_route.schema.json` — route-edge exchange schema;
- `chronology_event.schema.json` — authoritative event envelope;
- `seed_voyage.schema.json` — seed mission state;
- `first_reconnection.example.json` — Echo Two / Far Station benchmark fixture;
- `validation_profile.json` — hard gates and required proofs.
