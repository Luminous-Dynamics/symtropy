# Worldline Characters v0.1 Fixtures

This fixture set supports the v2.5 multi-character and interstellar-succession design campaign.

Files:

- `character_profile.schema.json` — worldline-qualified playable character record;
- `observer_knowledge.schema.json` — character-bound knowledge and provenance;
- `succession_claim.schema.json` — domain-specific legal and civic claims;
- `three_generation_benchmark.example.json` — Far Station benchmark roster and branches;
- `validation_profile.json` — minimum proof gates.

These schemas are design contracts, not evidence of runtime implementation.
