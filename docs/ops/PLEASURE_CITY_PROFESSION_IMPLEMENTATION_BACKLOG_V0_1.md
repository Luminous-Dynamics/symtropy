# Pleasure City Profession Implementation Backlog

## Objective

Prove deep professions in one bounded district before generalizing the system across the whole game.

# Phase 0 — Shared Data

- stable profession, practitioner, tool, crew, work-order, shift, project, handover, credential, and exposure IDs;
- deterministic event journal;
- privacy scopes;
- compensation and custody links;
- save migration fixtures.

# Phase 1 — Three Vertical Professions

Implement first:

1. sanitation and recovery worker;
2. nightlife medic;
3. maintenance technician.

These three prove material, care, evidence, utilities, cleanup, handover, and shift continuity without requiring adult-content rendering.

# Phase 2 — Public Trust

Add:

- gambling auditor;
- licensing inspector;
- de-escalation specialist.

Prove evidence, authority, appeal, corruption pressure, and public hearing integration.

# Phase 3 — Service and Culture

Add:

- performer;
- hospitality worker;
- transit operator;
- dealer;
- substance steward.

Prove crowds, schedules, cultural seasons, visitor flows, and worker economics.

# Phase 4 — Adult Venue Proof

Add the adult-service worker packet only after:

- adulthood verification;
- consent state;
- privacy;
- worker-controlled boundaries;
- coercion indicators;
- player content controls;
- subject review;
- non-explicit authored presentation;
- multiplayer moderation boundaries

are implemented and tested.

# Phase 5 — Career and Apprenticeship

Prove:

- two practice styles per profession;
- one apprentice transfer test;
- one occupational accommodation;
- one credential dispute;
- one long-absence career change;
- one worker becoming a supervisor, organizer, owner, teacher, or regulator.

# Evidence Requirements

Each ticket must attach:

- code path;
- schema version;
- deterministic replay;
- save/load evidence;
- performance trace;
- privacy review;
- accessibility review;
- content review;
- playtest observation;
- known limitations.

No profession moves above I0 without evidence.
