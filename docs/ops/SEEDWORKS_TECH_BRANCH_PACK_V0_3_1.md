# Symtropy: Seedworks Tech Branch Pack v0.3.1

## Working Title

**The Future Must Be Maintained Before It Can Be Inherited**

## Core Thesis

This branch pack extends the Seedworks technology tree beyond the v0.1–v0.3 playable spine while preserving the core rule of the Infrastructure Loom:

```text
A technology is not unlocked because the player spent points.
It is unlocked because the world can now carry its material, power, computation, legitimacy, maintenance, and consequence.
```

Future technology in *Symtropy* should never become a magical ladder.

It should remain a public dependency graph.

Robots, living infrastructure, orbital systems, deep-space habitats, and interstellar precursors all obey the same grammar as the first pipe:

```text
matter
power
computation
legitimacy
maintenance
consequence
```

Design rule:

```text
The first pipe and the first starship are part of the same moral machine.
One proves that repair is possible.
The other proves that repair can survive distance.
```

Do not add future tech as spectacle.

# 10. Branch D — Robotics and Automation Roadmap

## Purpose

Robotics is where human disciplines become embodied.

A robot is not a pet, a minion, or a generic labor upgrade.

In *Symtropy*, a robot is:

```text
a machine body
a Device Bus node
a power load
a maintenance liability
a civic actor under permission
a possible witness
a labor dispute
a future failure mode
```

Core rule:

```text
The first robots should extend sight, carrying, listening, and witnessing.
They should not replace the player.
```

## D.1 Robotics Autonomy Ladder

Use this autonomy ladder consistently for all robot nodes.

| Level | Name | Meaning | Example |
|---:|---|---|---|
| L0 | Manual Tool | Direct human control only | hand winch, manual gantry |
| L1 | Assisted Device | Performs bounded action while held or supervised | guided ribbon, acoustic alert |
| L2 | Supervised Routine | Can follow a route or repeat a task under live oversight | mk0-scout Cable-Crawler |
| L3 | Bounded Task Agent | Can complete a local task with route/zone limits | warehouse rover, agribot plot pass |
| L4 | Public Works Agent | Can coordinate with other devices under charter | repair swarm, foundry tender |
| L5 | Stewardship Agent | Can manage long-horizon maintenance under audit | habitat life-support steward |
| L6 | Remote / Delayed Steward | Can operate under high latency with compressed witness logs | lunar regolith robot, Ceres depot agent |
| L7 | Precursor Autonomy | Can operate beyond normal human intervention under sacred constraints | interstellar probe / ark steward |

Design rule:

```text
Autonomy level is not intelligence level.
It is permission under risk.
```

## D.2 Robotics Permission Envelope

Every robot node needs a permission envelope.

```text
operating zone
route limits
human proximity rules
privacy boundary
power draw budget
witness capacity
allowed verbs
forbidden verbs
emergency recall path
maintenance owner
appeal path
```

Forbidden:

```text
robot node with no civic permission
robot node with no recall path
robot node with no maintenance dependency
robot node with no failure mode
robot witness with no contest procedure
```
