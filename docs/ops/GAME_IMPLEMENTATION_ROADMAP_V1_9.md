# Symtropy Game Implementation Roadmap

## Strategy

Stop broad feature expansion until one place proves the game.

Build Firstlight in evidence-gated layers. At every gate, test physical enjoyment, clarity, attachment and accessibility before adding more content.

# Gate A — Ten-Minute Contact

Implement:

- responsive embodiment;
- stopped crawler;
- Sera and Bram;
- Bent Feeder;
- IRIS uncertainty;
- three approaches;
- persistent outcome.

**Exit:** players control quickly, understand the human need and enjoy the interaction.

# Gate B — First-Hour Home

Implement:

- walk into Firstlight;
- Commons;
- private room and storage;
- three profession doors;
- three recurring people;
- rest and return.

**Exit:** players know where they are and choose a direction.

# Gate C — Three Profession Foundations

Implement one safe and one live case for:

- maintenance;
- field medicine;
- civic witness.

**Exit:** each has unique tempo, cue and judgment.

# Gate D — Four-Landmark Recurrence

Implement Bent Pump, Rain Court, Clinic Courtyard and Transit Board across at least two states.

**Exit:** players navigate and remember them without constant markers.

# Gate E — Bridge Seven

Implement movement, rescue, companion initiative, optional combat, machine authority and aftermath.

**Exit:** action is exciting and damage persists.

# Gate F — Ordinary Evening

Implement market, meal, rehearsal or game, cleanup and low-pressure NPC contact.

**Exit:** players voluntarily remain or revisit without objective reward.

# Gate G — Ten-Hour Identity

Add:

- intermediate profession case;
- Lower Works entry;
- hearing;
- delayed consequence;
- wider horizon.

**Exit:** players remember people and places and express a self-chosen next desire.

# Gate H — Twenty-Hour Regional Life

Add:

- multi-session project;
- two practiced companion procedures;
- optional Flooded Annex expedition;
- festival preparation;
- independent NPC project progression.

# Gate I — Firstlight Night

Implement cultural event before crisis, concurrent fronts, action, rescue, destruction and companion autonomy.

**Exit:** event is exciting and causally assembled from prior state.

# Gate J — Aftermath and Hearing

Implement cleanup, care, repair, record, rumor, labor and public process.

**Exit:** at least five consequences remain materially visible.

# Gate K — Continuity and Absence

Implement bounded death/reconstitution case, chosen time passage and changed return.

**Exit:** no world reset, no offline guilt, clear summary.

# Gate L — Forty-Hour Benchmark

Run full build through three worldlines and accessibility profiles.

# Gate M — Delayed Recall

Run seven-day unaided recall and return study.

**Exit:** evidence supports production continuation or identifies specific failures.

# Gate N — Controlled Expansion

Only after Gate M:

- deepen professions;
- add another region;
- add broader construction;
- add another playable character;
- expand orbital content;
- restore selected long-horizon priorities.

# Production Order

```text
contact
→ home
→ practice
→ landmark recurrence
→ danger
→ ordinary life
→ identity
→ project
→ major event
→ aftermath
→ absence
→ recall
```

# Explicit Deferrals

Before Gate M, do not prioritize:

- broad galactic content production;
- many worldline characters;
- universal FTL gameplay;
- dozens of professions;
- full planet simulation;
- huge procedural cities;
- wide weapon catalogue;
- extensive alien campaign roster.

## Roadmap Maxim

> **Do not scale the universe until one evening in Firstlight is already worth remembering.**
