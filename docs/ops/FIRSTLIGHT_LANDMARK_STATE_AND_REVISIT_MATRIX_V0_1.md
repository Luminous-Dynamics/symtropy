# Firstlight Landmark State and Revisit Matrix

## Purpose

A landmark is not proven by one memorable entrance. It is proven through changed use.

# Required Matrix

| Landmark | First use | Second use | Crisis use | Return use | Profession readings |
|---|---|---|---|---|---|
| Bent Pump House | emergency isolation | load test | regional dependency | aged repair or replacement | acoustic, clinical injury, custody |
| Commons Rain Court | arrival | evening market | triage/staging | new routine or memorial | social, logistical, evidentiary |
| Clinic Courtyard | waiting | private conversation | overflow recovery | changed staffing | clinical, relational, accessibility |
| Shared Repair Table | tool introduction | apprenticeship | emergency fabrication | inherited modifications | materials, ownership, handover |
| Bird Route | incidental path | Morrow-7 practice | evacuation conflict | ecological change | machine, ecology, social memory |

| Quiet Room | optional refuge | private support | overload recovery | respected privacy | care, consent, sound |
| Departure Platform | distant horizon | work visit | arrival/evacuation | choice or farewell | logistics, identity, future |

# State Layers

Every anchor landmark stores:

- physical condition;
- accessibility;
- current function;
- scheduled users;
- informal users;
- legal authority;
- public reputation;
- private associations;
- evidence and records;
- sound state;
- weather exposure;
- repair history;
- local name variants.

# Revisit Rules

A revisit should change at least one of:

- route;
- task;
- person present;
- sensory state;
- authority;
- social meaning;
- physical condition;
- player capability.

A location may remain physically unchanged when the player's knowledge or relationship changes.

# Memory Hooks

Each landmark receives:

- one repeatable sound;
- one local phrase or joke;
- one practical affordance;
- one person strongly associated with it;
- one state transition;
- one optional secret;
- one reason to visit without an objective.

# QA Questions

- Can a tester recognize the landmark from sound alone?
- Does it support at least three activities?
- Can it change without losing its identity?
- Is one visit emotionally quiet?
- Does damage persist?
- Can NPCs use it without the player?
- Does at least one profession perceive something unique there?
- Is there a plausible sanitation, power, access, and maintenance story?

## Matrix Maxim

> **Revisiting a place should reveal either what happened to it or what happened to the player.**
