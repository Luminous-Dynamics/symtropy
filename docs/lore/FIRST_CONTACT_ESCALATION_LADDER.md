# Symtropy First Contact Escalation Ladder

## Version 0.1 — From Trace to Confluence

## Purpose

This document defines the dramatic and mechanical progression of alien contact in **Symtropy: Seedworks**.

The alien taxonomy explains what kinds of nonhuman agency exist.

This document explains how the player encounters them over time.

The goal is to prevent aliens from arriving as a sudden genre shift. First contact should deepen through stages:

```text id="psfj3v"
trace
response
boundary
witness
misread contact
reciprocal risk
irreconcilable boundary
confluence
```

## Core Principle

```text id="i3s6yb"
The player should learn first-contact ethics before meeting anything that can speak back.
```

## Stage Summary

```text id="db6p9r"
Stage 0 — No Aliens in the First Pump
Stage 1 — Alien Trace
Stage 2 — Reactive Ecology
Stage 3 — Boundary Negotiation
Stage 4 — Nonhuman Witness
Stage 5 — Misread Contact
Stage 6 — Reciprocal Risk
Stage 7 — Irreconcilable Boundary
Stage 8 — Confluence Contact
```

# Stage 7 — Irreconcilable Boundary

## Location

```text id="b7zog2"
Active Bloom Basin / Acid Sea Edge / Swarm Reproduction Zone / Quarantine Boundary
```

## Contact Level

```text id="dlxeum"
mutual recognition without cohabitation
```

## Purpose

Teach that ethical repair sometimes means withdrawal.

## Situation

The player encounters a nonhuman system whose core viability condition is incompatible with human settlement in the same zone.

This is not a villain encounter.

It is a tragic overlap.

## Concrete Scenario: Red Bloom Active Basin

The Bloom’s mature basin can purify a regional water table, but its active metabolic zone makes permanent human habitation unsafe.

The settlement wants to remain.

The Bloom cannot remain alive if forced into a narrow artificial membrane.

Both claims are real.

# Implementation Strategy

## Do Not Build All Stages at Once

Stage 1–4 are the first alien implementation target.

Stage 5–8 remain authored, not fully simulated, until Red Bloom mechanics prove playable.

## Recommended Build Order

```text id="u6euyf"
1. Red Bloom Trace
2. AgencyUncertaintyRecorded event
3. BoundaryEstablished event
4. NonhumanWitnessRecorded event
5. One faction conflict around containment
6. One reciprocal-risk choice
7. One irreconcilable boundary scene
8. One Confluence treaty scene
```

## Minimal First Implementation

```text id="l381nh"
one Red Bloom prop/decal
one Field Deck uncertainty panel
one contain-or-burn choice
one Chronicle event
one future NPC citation
```

## Final Principle

```text id="q1lp7g"
First contact begins as classification.
It becomes ethics when classification fails.
```
