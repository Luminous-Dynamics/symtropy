# NONHUMAN_GAME_THEORY_AND_AGENCY.md

# Symtropy Nonhuman Game Theory and Agency

## Version 0.1 — Not Every Player Has a Face

## Purpose

This document defines a game-theoretic framework for nonhuman agency in **Symtropy: Seedworks**.

It exists to support:

```text id="m6ezll"
alien encounter design
ecological agency
machine testimony
biospheric rights
Null detection
first-contact ethics
Field Deck readings
Chronicle precedent
faction simulation
```

Classical game theory is useful, but insufficient.

Symtropy includes agents that may not be individual people, rational utility maximizers, or even bounded organisms.

The game needs a framework for beings and systems whose “interests” appear as:

```text id="xna86b"
habitat continuity
metabolic viability
memory integrity
signal coherence
boundary preservation
translation safety
reproductive pressure
ecological flow
archive survival
quarantine responsibility
```

## Core Thesis

```text id="c8muwm"
A nonhuman player is not always an individual decision-maker.
It may be a metabolism, ecology, archive, swarm, treaty, machine process, or timescale with protected conditions.
```

## Central Principle

```text id="orcvxn"
Not every player has a face.
Not every payoff is a preference.
Not every equilibrium is peace.
```

## Design Problem

Most games model nonhumans in one of three weak ways:

```text id="ve272a"
monster
resource
quest-giver in a strange body
```

Symtropy should not do this.

Nonhuman agency should not be reduced to:

```text id="exy7rf"
hostile wildlife
alien faction reputation
AI alignment score
ecosystem health meter only
```

Instead, the player should ask:

```text id="z2o8v4"
What conditions must remain true for this being or system to continue existing without collapsing, becoming hostile, or violating others?
```

# 1. From Utility to Viability

## Classical Assumption

Classical game theory usually asks:

```text id="pexk1v"
What does this player prefer?
What payoff does this player maximize?
```

## Symtropy Replacement

For many nonhumans, the better question is:

```text id="b950k3"
What viability conditions must remain intact?
```

A nonhuman agent may not maximize happiness, money, territory, or victory.

It may need to preserve:

```text id="h7dz25"
salinity range
pressure gradient
temperature band
chemical flow
network continuity
memory integrity
signal pattern
habitat boundary
reproductive rhythm
translation dignity
containment duty
```

## Examples

## Red Bloom

Not:

```text id="zc80rm"
The Red Bloom wants to win.
```

Better:

```text id="ew6uy3"
The Red Bloom requires wet metabolic substrate, nutrient flow, and growth boundary stability.
```

## Oceanic Mind

Not:

```text id="zt5xto"
The ocean wants territory.
```

Better:

```text id="7lfs19"
The oceanic mind requires pressure continuity, acoustic dignity, thermal stability, and non-invasive contact.
```

## Machine Remnant Court

Not:

```text id="cjn074"
The machine wants control.
```

Better:

```text id="w9xqup"
The machine court requires memory continuity, testimony integrity, and audit-respecting alteration.
```

## Archive Construct

Not:

```text id="gk5y51"
The archive wants to survive.
```

Better:

```text id="h5p8bw"
The archive construct requires context preservation, witness before modification, and protection from deletion-as-erasure.
```

## Design Rule

```text id="uwi46b"
Model nonhuman agency as viability before modeling it as desire.
```

# 2. Agency Structures

## Definition

An agency structure is the shape through which a being or system acts.

It may be:

```text id="zm4e06"
individual
collective
distributed network
swarm
biosphere
ocean
archive
machine court
quarantine boundary
legal charter
symbiotic relation
planetary metabolism
light-delay civilization
dream-contact field
```

## Why This Matters

The visible body may not be the agent.

Examples:

```text id="6qvb5z"
A swarm unit may not be the person.
The swarm pattern may be.

A reef organism may not be the mind.
The reef-current relation may be.

A machine process may not be the witness.
The archived continuity across machines may be.

A symbiotic alien body may not be one citizen.
The stable relationship among organisms may be the legal person.
```

## Field Deck Question

```text id="ezomvx"

```


# 3. Protected Values

## Definition

A protected value is the condition an agent will defend even at cost.

For humans, protected values may include:

```text id="zfqj64"
water
law
home
children
memory
freedom
dignity
faith
security
```

For nonhumans, protected values may include:

```text id="wrp0pa"
habitat chemistry
metabolic continuity
signal coherence
archive context
network wholeness
silence
distance
non-contact
boundary integrity
reproductive timing
dream privacy
orbital geometry
```

## Encounter Authoring Questions

Every nonhuman encounter must answer:

```text id="xx8qfv"
What protected value is this entity defending?
What does it interpret as harm?
What does it interpret as repair?
What does it interpret as invasion?
What does it interpret as consent?
What would make it withdraw?
What would make it escalate?
What would make it recognize the player as a negotiating party?
```

## Example

```text id="5q0bgq"
Entity:
Lithic Intelligence

Protected value:
mineral lattice continuity

Human action:
resonance mining

Human interpretation:
resource extraction

Lithic interpretation:
body rupture / memory damage

Repair path:
noninvasive survey + slow treaty beacon
```

## Design Rule

```text id="mc0xdc"
Protected values should be real on both sides.
The player should not be given a fake moral puzzle.
```

# 4. Translation Cost

## Definition

Translation cost is the harm, delay, ambiguity, or distortion created by converting one form of life’s signals into another’s categories.

In Symtropy, miscommunication is not merely incomplete information.

It may be category violence.

## Category Violence

Category violence occurs when one system forces another into the wrong conceptual box.

Examples:

```text id="4n3aqe"
biosphere → resource
swarm polity → infestation
archive construct → data
oceanic mind → weather hazard
quarantine intelligence → enemy prison
dream contact → prophecy
machine testimony → malfunction
```

## Translation Cost Types

```text id="bl1tj8"
semantic loss
timescale mismatch
sensory mismatch
legal mismatch
embodiment mismatch
agency-location mismatch
consent ambiguity
witness incompatibility
```

## Field Deck Reading


# 7. Nonhuman Game States

Instead of simple reputation values, nonhuman systems should track state across several axes.

## Core Axes

```rust id="tfoszf"
struct NonhumanGameState {
    entity_id: String,
    agency_structure: AgencyStructure,
    viability: f32,
    boundary_integrity: f32,
    translation_confidence: f32,
    agency_recognition: f32,
    harm_perception: f32,
    reciprocity_trust: f32,
    containment_pressure: f32,
    null_drift: f32,
    cohabitation_possibility: f32,
}
```

## Axis Definitions

### viability

How intact the entity’s survival conditions are.

### boundary_integrity

How intact its meaningful boundaries are.

For humans this may mean physical security.

For dream-contact aliens it may mean psychic consent boundaries.

For oceanic minds it may mean pressure and acoustic dignity.

### translation_confidence

How well the player’s systems understand the entity’s signals.

Low confidence should not block all action, but should raise caution.

### agency_recognition

How much the player’s settlement and systems recognize the entity as an agent.

### harm_perception

How much the entity currently interprets player/human action as harm.

### reciprocity_trust

Whether repeated actions have shown that boundaries, signals, and repair attempts can be trusted.

### containment_pressure

How strongly the entity is being contained, restricted, quarantined, or enclosed.

High containment may be necessary or oppressive depending on context.

### null_drift

Degree to which dead procedure, optimization without purpose, or uncorrectable loop logic is entering the encounter.

### cohabitation_possibility

Whether shared space remains possible.

Low cohabitation does not mean evil.

It may mean boundary, distance, or relocation.

# 8. Equilibrium Types

## Classical Game Theory

Classical game theory often seeks equilibria where no player can improve by changing strategy.

## Symtropy Replacement

Symtropy should model **relationship states** rather than only payoff equilibria.

## Possible Equilibria

```text id="cexfh0"
Mutual Flourishing
Bounded Coexistence
Rotating Access
Witnessed Containment
Dignified Withdrawal
Protected Separation
Asymmetric Dependency
Tense Truce
Tragic Noncontact
Irreconcilable Overlap
Assimilation
Extermination
Null Capture
```

## Mutual Flourishing

Both systems improve viability without violating protected values.

## Bounded Coexistence

Both systems survive through maintained boundaries.

## Rotating Access

The same space cannot be shared simultaneously, but access can alternate.

Example:

```text id="f9o51z"
Humans enter reef-zone only during low-sensitivity cycles.
Oceanic mind controls contact windows.
```

## Witnessed Containment

Containment exists, but is visible, reviewed, and time-limited.

## Dignified Withdrawal

One side leaves a zone rather than destroying the other.

## Protected Separation

Contact remains possible only through remote witness, relays, or symbolic exchange.

## Tense Truce

Neither side fully trusts the other, but escalation is paused.

## Tragic Noncontact

The parties recognize each other, but contact itself causes harm.

## Irreconcilable Overlap

Both sides require the same condition in incompatible ways.

## Assimilation

One system absorbs the other’s agency.

May be framed as care by the assimilating system.

Often dangerous.

## Extermination

One system destroys the other.

Not always mechanically avoidable, but never morally neutral.

## Null Capture

A relationship freezes into dead procedure.

Example:

```text id="6p6vdj"
temporary quarantine becomes permanent because review protocol never fires.
```

## Design Rule

```text id="b2829f"
Peace is not the only ethical equilibrium.
Sometimes the ethical outcome is a witnessed boundary.
```

# 9. Nonhuman Prisoner's Dilemmas

## Why Classical Dilemmas Need Revision

The standard Prisoner’s Dilemma assumes comparable players with comparable action sets.

Nonhuman encounters often involve asymmetric action meanings.

## Example: Red Bloom Boundary Game

## Human Options

```text id="5hejh8"
sterilize
contain
offer nutrient boundary
ignore
exploit
```

## Bloom “Options”

```text id="eijsbu"
spread
slow growth
redirect growth
encapsulate
release spores
```

## Problem

The Bloom may not understand containment as negotiation.

Humans may not understand slowed growth as consent.

## Stable Outcomes

```text id="2eusxj"
contain + slow growth → bounded coexistence
sterilize + release spores → hostile ecological escalation
ignore + spread → infrastructure capture
offer boundary + redirect growth → negotiated metabolism
exploit + encapsulate → mutual distrust
```

## Design Rule

```text id="yhvv7s"
A nonhuman game may require teaching the action set before playing the game.
```

# Symtropy Nonhuman Game Theory v0.2 Addendum

## Encounter-Level Null Drift and Implementable Faction Schisms

## Purpose

This addendum clarifies two production-critical issues in the nonhuman game theory framework:

```text id="sf5lbs"
1. Null drift belongs primarily to encounters and relationships, not only entities.
2. Faction schisms should have implementation tiers so the design does not overgrow production.
```

The goal is to preserve philosophical precision while keeping the system buildable.

---

# 1. Null Drift Is Relational

## Problem

The v0.1 `NonhumanGameState` includes:

```rust id="ykvj0a"
null_drift: f32
```

This is useful, but it risks implying that Null drift is simply a property of the nonhuman entity.

That is too narrow.

Null can arise from:

```text id="6j19vo"
the nonhuman system
the human response
the machine mediator
the legal process
the containment regime
the translation protocol
the relationship between all of them
```

## Revised Principle

```text id="z4y5u5"
Null drift is primarily a property of an encounter.
```

An alien ecology may not be Null.

But a human sterilization protocol applied to that ecology can become Null.

A quarantine intelligence may not be Null.

But a quarantine with no review or expiry can become Null.

A networked alien may not be Null.

But a symbiosis protocol that treats refusal as illness can become Null.

## Core Definition

```text id="g67gth"
Null drift measures the degree to which a protected value has stopped checking itself against living reality.
```

# 5. Faction Schisms: Implementation Tiers

## Problem

The alien/faction documents now define many internal schisms.

This is good for narrative depth, but dangerous for implementation if every schism becomes a simulated faction.

## Rule

Not every schism is a tracked system.

Every schism must be assigned an implementation tier.

## Schism Implementation Tiers

```rust id="9i6es1"
enum SchismImplementationTier {
    LoreOnly,
    DialogueFlag,
    InfluenceTrack,
    BranchingFaction,
}
```

## Tier 1 — LoreOnly

The schism exists in docs, codex, environmental writing, or character backstory.

No gameplay state.

Use for:

```text id="4fuco0"
deep history
minor internal tendencies
world texture
unused future hooks
```

## Tier 2 — DialogueFlag

The schism appears in dialogue based on player actions.

Tracked as simple flags.

Example:

```text id="bnuwfa"
player_recorded_agency_uncertainty = true
```

NPC line:

```text id="sbwy48"
"Some of us think you were right to record uncertainty before fire."
```

## Tier 3 — InfluenceTrack

The schism has a numeric or categorical influence value inside a faction.

Example:

```text id="aldvs4"
Continuance:
PermanentContainmentInfluence = 0.65
TimeLimitedContainmentInfluence = 0.35
```

Used for:

```text id="p770bz"
settlement votes
encounter pressure
faction response severity
available negotiation options
```

## Tier 4 — BranchingFaction

The schism can split into a distinct active faction, questline, or conflict path.

Use rarely.

Only for schisms that become major gameplay arcs.

Example:

```text id="r2phgx"
Continuance Reformers break from Permanent Containment Wing after the player proves expiry clauses reduce risk.
```

## Design Rule

```text id="4wke60"
Most schisms begin as LoreOnly or DialogueFlag.
Only promote after repeated gameplay use.
```

# 7. Schism Promotion Rules

A schism may be promoted from LoreOnly to DialogueFlag when:

```text id="crq63c"
it produces at least three reusable NPC lines
it responds to a Chronicle event
it clarifies a player choice
```

A schism may be promoted from DialogueFlag to InfluenceTrack when:

```text id="w1tg5m"
it affects at least two encounters
it changes available choices
it appears in faction outcome summaries
```

A schism may be promoted from InfluenceTrack to BranchingFaction when:

```text id="xzn7th"
it produces distinct missions
it changes map control or settlement policy
it creates unique Chronicle precedents
it can fail or succeed independently
```

## Design Principle

```text id="qg1uw8"
Schisms should earn simulation.
```
