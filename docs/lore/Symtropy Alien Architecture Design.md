# Symtropy Alien Architecture Design Bible

## Version 0.1 — Built Worlds Beyond Human Assumptions

## Core Thesis

Alien architecture in Symtropy is not “strange buildings.”

Alien architecture is the visible result of nonhuman life solving the problems of:

```text
shelter
memory
care
repair
consent
danger
communication
reproduction
mourning
governance
territory
continuity
```

with bodies, senses, and social structures unlike ours.

A true alien architecture family should answer:

```text
What body is this built for?
What sense is this place designed to speak through?
What does this civilization consider sacred?
How does this society remember?
How does it repair?
How does it decide?
How does it exclude?
What does it misunderstand about humans?
What do humans misunderstand about it?
```

Alien architecture should be playable as a translation problem, not just viewed as scenery.

---

# 1. Prime Design Rule

Do not design alien architecture by asking:

```text
What would look weird?
```

Ask:

```text
What would a nonhuman society need to build if it did not share human assumptions about walls, doors, property, speech, time, privacy, identity, death, or repair?
```

Then ask:

```text
How can the player read that through space?
```

# 4. First-Contact Architecture Types

These are not full civilizations. They are encounter spaces that can appear between families.

## 4.1 Consent Threshold

A boundary where entry requires translation, ritual, or behavioral proof.

Gameplay:

```text
prove non-hostile intent
learn local warning symbols
calibrate body distance
observe before acting
```

## 4.2 Miscommunication Scar

A place damaged by a past failed translation.

Gameplay:

```text
recover both sides of a misunderstanding
repair symbolic harm
rebuild trust
```

## 4.3 Shared Tool Embassy

A repair space where species exchange methods without fully sharing language.

Gameplay:

```text
learn alien repair logic
combine tools
avoid dangerous assumptions
```

## 4.4 Noncontact Observation Garden

A diplomatic site where beings interact indirectly through signals, fluids, light, or environmental changes.

Gameplay:

```text
slow diplomacy
pattern recognition
trust accumulation
```

## 4.5 Multi-Species Rights Forum

A civic architecture for deciding whether nonhuman testimony, personhood, territory, or consent counts under local law.

Gameplay:

```text
translate needs into charter language
mediate incompatible values
write precedent
```

# Final Principle

Alien architecture should not merely ask:

```text
Can humans live here?
```

It should ask:

```text
Can humans understand enough to behave well here?
```

The player’s challenge is not to conquer alien space.

The player’s challenge is to become a guest who can repair without erasing.
