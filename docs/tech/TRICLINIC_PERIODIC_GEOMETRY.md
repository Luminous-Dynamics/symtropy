# Triclinic Periodic Geometry: Contract and Validation Plan

**Implementation:** LatticePeriodicDomain<D> in symtropy-math, plus skew-cell AABB image enumeration in symtropy-physics.  
**Tracking:** [PHYS-TOPOLOGY-003 #2924](https://github.com/Luminous-Dynamics/symtropy/issues/2924).  
**Scope:** geometry and conservative broadphase candidates only; no PhysicsWorld integration.

## 1. Why a separate lattice type

The orthogonal PeriodicBox<D> remains the simple product-cell API. A skewed/triclinic cell is different: its periodic translations are generated by lattice basis vectors, and nearest-image selection is a closest-lattice-vector problem.

Let the full-rank cell basis be the matrix B, with basis vectors as columns. The cell origin is o, and enabled periodic directions are selected by a mask p_i.

A point has fractional coordinates

\[
f = B^{-1}(x-o).
\]

Canonical wrapping reduces only enabled fractional coordinates to the half-open interval [0,1). It returns the integer offset n rather than silently rewriting the identity of the original image:

\[
x = x_{\mathrm{canonical}} + Bn.
\]

For a displacement d, the minimum-image problem is

\[
\min_{n\in\mathbb Z^D,\;n_i=0\text{ if }p_i=0}
\lVert d-Bn\rVert_2.
\]

Component-wise rounding of fractional coordinates is only an initial candidate. It is not a generally valid closest-image solver for a skew basis.

## 2. Bounded closest-lattice-vector search

The current reference implementation:

1. Computes fractional displacement f = B^-1 d.
2. Uses component-wise rounding only to obtain an initial candidate and finite residual radius r0.
3. For each enabled lattice coordinate, uses the corresponding inverse-basis row q_i and Cauchy–Schwarz:
   \[
   |f_i-n_i| = |q_i\cdot(d-Bn)| \le \lVert q_i\rVert_2 r_0.
   \]
4. Builds an outward-rounded integer interval for every enabled n_i. Disabled axes are fixed at zero and checked against the necessary interval.
5. Enumerates the complete Cartesian product of those intervals, subject to an explicit candidate budget.
6. Returns the selected minimum residual, lattice offset, candidates examined, and whether the nearest image is unique within the floating-point tie tolerance.

If the interval product exceeds the configured search budget, the solver returns a typed error. It does not return the initial Babai-style candidate as if it were an exact nearest image.

This is a conservative bounded reference algorithm. It may over-enumerate badly on skew cells. A future QR sphere decoder or reduced-basis/LLL approach should be judged against this oracle, not substituted without differential evidence.

## 3. Ambiguous ties

Some displacements have more than one equally near image (for example, an exact half-cell displacement). The result exposes is_unique = false. A caller that needs a contact normal must adopt an explicit tie policy; the geometry layer must not pretend the direction is unique.

The current deterministic tie selector is reversal-odd: reversing the input displacement selects the reversed residual. This is covered by exact half-cell tests. It is not a claim that the closest image is physically unique.

## 4. Skew-cell AABB candidate generation

For AABB pair A,B, a translation s=Bn can overlap only if

\[
s_k \in [A_{\min,k}-B_{\max,k},\; A_{\max,k}-B_{\min,k}]
\quad\text{for every world axis }k.
\]

Applying row i of B^-1 to this world-space interval gives a conservative interval for lattice coordinate n_i. The implementation enumerates the resulting integer product and returns a deterministic candidate superset.

**Hard broadphase rule:** no actual overlapping image may be omitted. Extra images are permitted and counted as over-generation. The broadphase intentionally does not use a strict floating-point overlap filter to remove extras; narrow phase is responsible for rejection.

A budget-exhausted result is an error, not an empty candidate set.

## 5. Independent validation ladder

Current authored controls:

- skew 2D wrap/reconstruction with explicit image offsets;
- a skew cell where independent fractional rounding is not the closest image;
- 1,000 deterministic 2D closest-image cases against a bounded brute-force integer oracle;
- 128 deterministic 3D closest-image cases against a bounded brute-force integer oracle;
- exact half-cell tie ambiguity and displacement-reversal control;
- unimodular basis-change invariance;
- lattice-translation invariance;
- mixed periodic-subspace controls;
- invalid/singular basis and search-budget failure controls;
- skew 2D AABB image-set comparison against direct integer-image enumeration;
- skew 3D AABB no-miss comparison against direct integer-image enumeration;
- extended-AABB multi-image and nonperiodic-axis controls.

These are authored test definitions, not passing test evidence. They must run on the exact PR head.

## 6. Performance and SOTA comparison

For closest-image search, report by dimension, periodic rank, basis condition proxy, skew/tilt, displacement magnitude and search budget:

- agreement with an independent bounded brute-force oracle;
- distance residual and tie/ambiguity rate;
- candidate offsets examined;
- budget-exhausted and ill-conditioned cases;
- p50/p95/p99 latency and allocations.

For broadphase, report:

- no-miss rate against direct integer-image enumeration;
- candidate over-generation ratio;
- candidate-budget exhaustion rate;
- p50/p95/p99 latency across object extents, skew and periodic rank;
- subsequent narrow-phase calls and false-positive rejection cost.

Industry references are useful as semantic baselines, not as interchangeable end-to-end rigid-body benchmarks:

- **GROMACS** documents triclinic periodic cells and minimum-image semantics for molecular dynamics.
- **LAMMPS** supports triclinic boxes and tilt-coupled periodic image shifts.
- **CGAL** represents periodic triangulation with explicit image offsets and periodic geometry data structures.

The present work targets the cell/closest-image and conservative AABB candidate layer only. It does not compare full dynamics, electrostatics, triangulation or neighbor-list throughput.

This work models declared full-rank skew periodic lattices and bounded image search. It does not model arbitrary curved manifolds, prove physical extra dimensions, or establish pocket-universe physics.
