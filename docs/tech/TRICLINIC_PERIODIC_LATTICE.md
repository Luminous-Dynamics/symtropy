# Triclinic Periodic Lattice Geometry

**Status:** experimental reference implementation; exact-head execution required.  
**Tracking:** PHYS-TOPOLOGY-003, issue #2924.  
**Implementation:** crates/core/symtropy-math/src/periodic_lattice.rs.

## Why this is a separate abstraction

PeriodicBox represents orthogonal coordinate periods. A skewed or triclinic cell is generated by a basis matrix B whose columns are independent lattice translations. The equivalence relation is x ~ x + Bn for integer n.

Two operations that must not be conflated:

- Canonical reduction maps a point into the fundamental parallelepiped origin + B[0,1)^D. Fractional-coordinate floor is suitable for this representative choice.
- Minimum-image displacement solves argmin over integer n of ||d + Bn||. Rounding each fractional coordinate independently is not generally correct for a skewed basis.

The implementation is full-rank D=2/3. It deliberately does not pretend to support mixed periodic rank embedded in a nonperiodic complement; that requires an explicit subspace/metric contract.

## Current implementation

PeriodicLattice stores an origin, full basis, and twice-reorthogonalized modified-Gram-Schmidt QR factorization.

For minimum-image queries:
1. Transform the target with Q transpose.
2. Obtain an initial Babai nearest-plane integer vector by back substitution through R.
3. Use that solution's distance as a finite sphere radius.
4. Enumerate the complete integer search region inside that radius from the last QR coordinate upward.
5. Compare Cartesian candidate distances and apply lexicographic integer-offset tie-breaking.
6. Return the nearest displacement, integer image offset, distance squared and search-node count.

The caller supplies a node budget. Exhaustion returns SearchBudgetExceeded; the best-so-far candidate is not returned as proven optimal. A relative QR pivot threshold rejects degenerate/ill-conditioned bases. The reported pivot ratio is only a diagnostic proxy, not a spectral condition number.

## Deterministic semantics

- The canonical fractional interval is half-open [0,1) on every full-rank lattice coordinate.
- A wrapped point plus its explicit lattice offset reconstructs the original Cartesian point within floating-point tolerance.
- The closest-image convention minimizes Euclidean Cartesian distance, not fractional-coordinate distance.
- Exactly equal computed distances choose the lexicographically smallest integer image offset.
- Non-finite values, out-of-envelope integer image indices, degenerate basis pivots and exhausted search budgets are typed failures.

## Independent correctness corpus

The initial tests compare 2D and 3D closest-image results against bounded brute-force integer-offset enumeration. Metamorphic controls cover:
- lattice translation invariance;
- unimodular basis change (same lattice, different basis coordinates);
- Cartesian rotation/isometry;
- half-cell ties and deterministic image choice;
- wrapping reconstruction from explicit image offsets;
- orthogonal-lattice agreement with PeriodicBox away from tie boundaries;
- ill-conditioned basis rejection and search-budget exhaustion.

These are authored tests, not results. The brute-force oracle window must be wide enough for every fixture. The randomized tests use fixed seeds; all future failures should preserve the minimized displacement, basis, oracle window, and seed.

## Performance protocol

Compare the QR sphere decoder against brute-force lattice-offset enumeration on identical immutable query corpora. Sweep:
- D=2 and D=3;
- orthogonal, moderate-skew and strong-but-accepted skew bases;
- displacement magnitudes and nearest-image integer offsets;
- search-node budgets and basis pivot ratio;
- 64, 256, 1,024 and larger query corpora.

Report p50/p95/p99 query latency, search nodes, QR setup cost (separately amortized and one-shot), brute-force candidate count, maximum distance residual, failure rate and condition proxy. Pin the basis and query corpus digest, seed, compiler/toolchain, CPU and optimization flags. Do not report only a speed ratio: the oracle distance and integer image must agree first.

## Industry references and fair comparison

- GROMACS 2026.4 documents triclinic periodic boxes and minimum-image cutoff restrictions relative to the shortest box vector; some search algorithms impose additional restrictions. This is a mature molecular-dynamics implementation, not a generic rigid-body convex-collision baseline: https://manual.gromacs.org/documentation/current/reference-manual/algorithms/periodic-boundary-conditions.html
- LAMMPS documents restricted triclinic cells, tilt factors, box flips and the performance implications of strong skew. It is an appropriate operational comparator for cell semantics, not a like-for-like closest-vector microbenchmark: https://docs.lammps.org/stable/Howto_triclinic.html
- CGAL's 3D periodic triangulation explicitly represents points with integer image offsets on a flat torus. It is a useful geometry/data-structure comparator, though it solves triangulation rather than physics collision: https://doc.cgal.org/latest/Periodic_3_triangulation_3/index.html

The claim to test is narrow: a bounded, fail-closed 2D/3D closest-lattice-image query with explicit image identity and reproducible oracle checks. Triclinic periodicity itself is established prior art.

## Limitations and follow-on work

- Full-rank periodic directions only; no mixed periodic rank in a Euclidean complement yet.
- Orthogonal Euclidean metric only; no arbitrary Riemannian metric or curved manifold.
- QR sphere decoding can have exponential worst-case search growth as dimension/skew increases.
- No triclinic AABB/broadphase, convex periodic GJK, CCD or contact identity yet.
- No integration into PhysicsWorld.
- This is a declared periodic simulation cell, not evidence of compact extra dimensions or pocket universes.

Next gates: exact-head Rust tests, randomized 3D oracle expansion, randomized unimodular basis transformations, a closest-image benchmark, then conservative skew-cell broadphase. Physics integration remains blocked until each geometry/collision gate has independent no-miss evidence.
