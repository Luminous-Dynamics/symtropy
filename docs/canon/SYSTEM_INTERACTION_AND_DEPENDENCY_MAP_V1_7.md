# System Interaction and Dependency Map

## v2.4 Causal Spine

```text
worldline and regional truth
→ Atlas, local, proper, and knowledge time
→ seed mission and physical voyage
→ destination founding and local sovereignty
→ metric measurement and anchor construction
→ paired route proof
→ positive-latency transit
→ migration, trade, rescue, conflict, and culture
→ route failure or maintenance
→ reconnection history and galactic worldlines
```

# 1. Authority Boundaries

## Worldline Runtime

Owns event ancestry, branches, snapshots, and unique-asset location.

It does not decide civic authority or cultural meaning.

## Atlas Chronology

Owns future-directed event order and route-cycle validation.

It does not replace proper time or character knowledge.

## Relativistic Physics

Owns trajectories, velocity, proper time, acceleration, radiation, momentum, and vehicle dynamics.

It does not decide mission legitimacy.

## Knowledge Runtime

Owns observation, emission, reception, confidence, custody, and prediction age.

It does not expose current server state without a valid channel.

## Seed Voyage Runtime

Owns ship population, habitat, voyage advancement, mission state, and arrival.

It does not freeze descendants under launch authority.

## Metric Runtime

Owns field state, energy, heat, coherence, debt, route weather, and physical failure.

It does not own traffic law, migration, or quarantine authority.

## Civic and Route Authorities

Own offices, bounded permissions, traffic policy, public spending, and review.

They do not own private consent, source-chain identity, or destination society.

## Transit Transaction Runtime

Owns manifest freeze, reservation, commit, route custody, arrival, and reconciliation.

It may move unique state exactly once.

## Multiplayer Runtime

Owns player temporal location, region frontier, host service, and network ordering.

Host status grants no route or civic authority.

## IRIS

Owns bounded explanation, clock translation, evidence comparison, and warnings.

IRIS does not infer current remote truth, choose rescue priority, or certify alien routes without evidence.

# 4. Dependency Gates

## FTL Requires

- authoritative worldline;
- fixed-point Atlas Time;
- route graph;
- proper-time runtime;
- knowledge separation;
- unique-asset registry;
- route transaction journal;
- destination region;
- authority and quarantine;
- power and thermal simulation.

## Seed Voyage Requires

- households and NPC life course;
- professions and apprenticeship;
- ecology and resources;
- ship physics;
- deep-time advancement;
- mission governance;
- source chains;
- companion refusal and absence.

## Multiplayer Epoch Migration Requires

- player temporal location;
- region frontiers;
- deterministic advancement;
- host-safe snapshots;
- explicit future-join UX;
- worldline ancestry;
- uniqueness reconciliation.

# 5. Failure Ownership

- chronology uncertainty → chronology runtime locks route;
- field instability → metric runtime degrades or closes;
- invalid authority → route transaction refuses commit;
- quarantine uncertainty → reception remains blocked;
- worldline mismatch → multiplayer and chronology quarantine;
- crash during commit → transaction recovery journal;
- lost destination → rescue runtime and committed contingency;
- stale remote data → knowledge UI, not hidden correction;
- companion refusal → companion runtime, not party override.

# 6. Level of Detail

High detail:

- active player region;
- ship crisis;
- route opening;
- active transit;
- first contact;
- failure and rescue;
- public hearing.

Low detail:

- stable remote production;
- routine traffic;
- ordinary maintenance;
- quiet voyage years;
- background ecology.

Protected state remains explicit at every level.
