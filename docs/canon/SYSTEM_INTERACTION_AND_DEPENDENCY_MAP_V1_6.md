# System Interaction and Dependency Map

## v2.3 Causal Spine

```text
world state and prior claims
→ households and founding cohort
→ provisional compact
→ public-service work
→ charter and institutions
→ office and budget authority
→ commitments and campaigns
→ place and cultural adoption
→ absence and succession
→ legacy and worldline branches
```

# 1. Authority Boundaries

## World Simulation

Owns materials, ecology, population, bodies, infrastructure, time, hazards, and spatial truth.

It does not infer legal ownership or cultural meaning from physical placement.

## Claims Registry

Owns evidence-backed claims and conflicts.

It does not select a winner without valid process.

## Household and Life-Course Systems

Own residents, dependents, care, migration, homes, births, deaths, and ordinary continuity.

A settlement cannot create population as a building reward.

## Civic Runtime

Owns compacts, charters, offices, authority tokens, institutions, budgets, and public-service obligations.

It does not own private consent, professional truth, or historical interpretation.

## Profession Runtime

Owns embodied competence, tools, shifts, certification, handovers, and liability.

Office-holders cannot replace specialists through political authority.

## Companion Runtime

Owns requests, refusals, practiced coordination, independent projects, and relationship history.

Companion standing remains theirs and cannot be used as a settlement key.

## IRIS

Owns bounded assistance, evidence provenance, reminders, and uncertainty communication.

IRIS does not decide legitimacy, guilt, personhood, cultural meaning, or private opinion.

## Campaign Detector

Owns causal clustering and opportunity scheduling.

It does not mutate authoritative state to create drama.

## Culture Runtime

Owns cultural artifact provenance, group adoption, variants, and transmission.

It does not make a proposal culturally binding.

## Persistence and Worldlines

Owns snapshots, Chronicle ancestry, branch identity, authority-token ancestry, and deterministic replay.

Host authority and save ownership do not become civic authority.

# 2. Founding Event Flow

```text
1. actor proposes settlement intent
2. world and claim systems enumerate known prior claims
3. households and agents evaluate participation
4. provisional presence reserves resources
5. compact proposal is authored
6. rights and authority validators run
7. participants ratify, reject, or amend
8. public-service providers reserve labor and inputs
9. authoritative founding event commits
10. Chronicle records participants, dissent, claims, and uncertainty
```

No building placement can skip steps 2, 3, 6, or 7 when civic founding is claimed.

# 3. Public-Service Flow

```text
need forecast
→ budget and access rule
→ worker assignments
→ resource reservation
→ service operation
→ capacity and queue effects
→ maintenance debt
→ public record
→ review or emergency response
```

Services interact with economy, professions, health, mobility, ecology, information, and justice.

# 4. Charter Flow

```text
proposal
→ clause effect analysis
→ translation and accessibility
→ participation window
→ ratification evidence
→ authority issuance
→ implementation
→ challenge and precedent
→ amendment or succession
```

A charter compiler may calculate effects. It cannot replace political participation.

# 5. Emergent Campaign Flow

```text
Chronicle events
→ feature extraction
→ causal clustering
→ significance and privacy gates
→ initiating NPC or institution
→ opportunity roles
→ authored/procedural storylet
→ world action
→ consequence
→ interpretation
→ inheritance
```

Campaign generation is downstream of authoritative causality.

# 6. Player Promise and Office Flow

```text
proposal or duty
→ capacity and authority validation
→ witnessed commitment
→ reserved resources
→ progress and conflict
→ fulfillment, breach, substitution, or inheritance
→ audience-specific interpretation
→ legacy trace
```

Office actions require live authority tokens. Personal history cannot substitute for them.

# 7. Place Memory Flow

```text
site
→ design
→ materials
→ labor
→ use
→ repairs
→ events
→ local names
→ cultural representation
→ landmark recognition or rejection
→ preservation, reuse, demolition, or ruin
```

Landmark recognition is constituency-specific.

# 8. Cultural Flow

```text
creation
→ exposure
→ local use
→ social transmission
→ mutation
→ institutional or commercial adoption
→ opposition
→ intergenerational continuity or disappearance
```

Culture may feed back into reputation, place, festivals, politics, education, and worldline history.

# 9. Absence and Return Flow

```text
player absence record
→ delegation and office succession
→ LOD settlement simulation
→ named milestone preservation
→ campaign resolution
→ service and culture change
→ return packet
→ identity and authority validation
→ relationships and public interpretation
```

Return does not rewind state or restore permissions.

# 10. Multiplayer

Civic mutations require:

- worldline ID;
- valid authority proof;
- resource reservation;
- participant or witness requirements;
- deterministic event order;
- branch ancestry;
- privacy-safe replication.

Host migration must not change office holders, claims, charter, or institutional authority.

# 11. Integration Gates

The v2.3 vertical proof is blocked until:

- authoritative households exist;
- resource flows and public services conserve state;
- claims and privacy are represented;
- professions can staff services;
- authority tokens expire;
- Chronicle replay is deterministic;
- absence simulation preserves named events;
- worldlines preserve ancestry;
- IRIS respects evidence boundaries.

# 12. Cross-System Failure Tests

Test at least:

- player constructs on a disputed site;
- office-holder lacks professional competence;
- service needs conflict with ecological boundary;
- companion refuses use of their political standing;
- private information influences behavior but remains hidden;
- host disconnects during ratification;
- founder dies during office term;
- charter forks across worldlines;
- cultural symbol is rejected;
- landmark is demolished lawfully;
- successor improves a system the founder designed.

# Closing Rule

> **Founding becomes trustworthy only when physical work, civic authority, personal agency, public service, culture, memory, and persistence agree on what happened—without collapsing into one owner's state.**
