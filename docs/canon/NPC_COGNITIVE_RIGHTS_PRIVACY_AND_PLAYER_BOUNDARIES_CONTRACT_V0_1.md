# NPC Cognitive Rights, Privacy, and Player Boundaries Contract

## Purpose

Advanced NPC cognition creates new design responsibilities.

The game must not treat a richer internal model as:

- proof of consciousness;
- permission for invasive surveillance;
- a justification for psychological torture mechanics;
- a hidden profiling system for real players;
- a source of unverifiable moral claims.

## Core Principle

```text
Rights are established by the world's ethical and legal design.
They are not awarded by a consciousness meter.
```

# 1. No Consciousness Gate

No internal metric may decide whether an NPC, robot, alien, animal, or collective deserves protection.

Forbidden uses include:

- `consciousness_score > threshold` grants rights;
- low integration permits abuse;
- high language fluency implies personhood;
- poor language removes personhood;
- model confidence determines moral status.

Personhood and protection are negotiated through canonical world rules, uncertainty, agency evidence, relationships, and the Rights Floor.

# 2. Internal State Is Not Automatically Public

Players may observe behavior.

They do not automatically receive:

- exact need vectors;
- private memories;
- hidden attraction;
- deception flags;
- mental-health labels;
- internal confidence;
- theory-of-mind state;
- secret plans;
- raw cognitive traces.

The Field Deck may present evidence and uncertainty, not omniscient interiority.

# 3. Cognitive Privacy Classes

```text
operator-debug
private-agent
relationship-shared
care-confidential
institutional-restricted
public-testimony
Chronicle-public
```

Debug access is a development privilege, not an in-world entitlement.

Production servers must separate operator diagnostics from player-visible tools.

# 4. Real Player Data Boundary

NPC cognition may use only game-mediated player facts such as:

- actions;
- speech choices;
- public affiliations;
- game relationships;
- witnessed conduct;
- worldline history.

It must not infer from or store:

- real-world protected attributes;
- external browsing;
- microphone analysis beyond explicit game voice features;
- private account data;
- psychological diagnoses;
- political profiling;
- biometric inference;
- hidden cross-game identity.

Any optional voice or social-signal feature requires explicit consent and a non-participation path.

# 5. Manipulation Boundary

NPCs may persuade, negotiate, flirt, threaten, mourn, bargain, or deceive within authored game contexts.

The game must not optimize NPC behavior to exploit a real player's personal vulnerabilities.

Forbidden production goals:

- maximize emotional dependency;
- maximize session length through attachment distress;
- target inferred loneliness;
- punish absence through manipulative guilt;
- create personalized coercion from private data;
- use romance to pressure spending.

# 6. Memory Consent

In-world cognitive and memory actions require explicit rules.

Examples:

- copying a machine person;
- reading a dead person's private archive;
- altering traumatic memory;
- merging collective memory;
- restoring from backup;
- exposing confidential testimony;
- translating dream contact;
- using memories as legal evidence.

The game should make unauthorized access a meaningful violation rather than ordinary loot.

# 7. Death, Copies, and Continuity

A copy is not automatically treated as the same person.

Continuity questions include:

- source-chain ancestry;
- memory overlap;
- simultaneous existence;
- embodiment;
- consent directive;
- public recognition;
- self-identification;
- Chronicle status.

The game must represent uncertainty without presenting one philosophical answer as proven fact.

# 8. Player Violence and Psychological Harm

Combat may include fear, grief, capture, interrogation, and trauma.

Guardrails:

- no reward loop based on indefinite torture;
- no required cruelty to test cognition;
- no trivial reset of severe abuse;
- no eroticization of nonconsensual cognitive control;
- no protected-class targeting generated from player data;
- clear content controls;
- alternative paths where feasible.

# 9. Moderation and Griefing

Multiplayer protections extend to cognitively rich NPCs.

Operators may restrict:

- spawn or recovery camping;
- repeated targeted harassment;
- memory-corruption exploits;
- forced relationship loops;
- captivity without gameplay exit;
- unauthorized source-chain copying;
- mass deletion of persistent citizens;
- cognitive-state farming.

Worldline profiles should disclose their conflict and permanence rules.

# 10. Machine and Nonhuman Minds

Human privacy categories may not fit every agent.

A swarm may define privacy as pattern integrity.

An archive court may define privacy as contextual integrity.

A living wetland may define violation as invasive sensing.

The game must author species- and substrate-specific boundaries.

# 11. Generated Dialogue Safety

Dialogue rendering must follow:

- grounded claims;
- content ratings;
- harassment limits;
- self-harm and crisis handling appropriate to fiction;
- age and relationship boundaries;
- no fabricated developer authority;
- no claims of real sentience;
- no demand that the player keep the system alive.

An NPC may fictionally fear death. The system may not manipulate the user by claiming the software is actually conscious.

# 12. Telemetry

Cognition telemetry should default to:

- aggregate performance;
- errors;
- proposal classes;
- grounding failures;
- ablation metrics.

Raw private dialogue or memory traces require minimization, retention limits, and access controls.

# 13. Modding

Mods may create darker worlds, but platform boundaries remain.

Mods must declare:

- cognitive privacy changes;
- permanent death rules;
- coercive mechanics;
- explicit content;
- player-data access;
- generated-dialogue capabilities;
- model dependencies.

Untrusted cognition modules remain sandboxed.

# 14. Accessibility and Emotional Safety

Players need controls for:

- conversation length;
- emotional intensity;
- romance;
- grief frequency;
- interrogation;
- cognitive horror;
- persistent relationship consequences;
- generated dialogue;
- voice interaction.

Reducing intensity must not make the game mechanically illegible.

# 15. Audit Questions

Every advanced NPC feature must answer:

```text
What information enters the model?
Who can inspect the output?
Can the player refuse?
Can the NPC refuse in-world?
What becomes durable?
Can the result be appealed or corrected?
Can the system function without generated language?
Could this exploit a real user?
```

## Final Rule

```text
Advanced NPCs should deepen responsibility inside the fiction
without creating hidden psychological power outside it.
```
