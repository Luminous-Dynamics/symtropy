# System Interaction and Dependency Map

## Purpose

Identify the minimum integrated truth required for a unique Firstlight to become loved, break causally, and continue inside a physically constrained mobile base.

# 1. Opening Causal Spine

```text
worldline cast seed
→ persistent people and households
→ ordinary life and player attachment
→ observations and warnings
→ preparation
→ coupled-system threshold
→ evacuation routes and independent decisions
→ survivor and continuity ledger
→ physical loading
→ mobile-base departure
→ post-title travel and later return
```

Every arrow requires authoritative state and replay evidence.

# 2. Unique Cast Dependencies

Cast generation depends on:

- worldline identity;
- role anchors;
- naming and culture packs;
- bodies and voices;
- household constraints;
- workplaces and schedules;
- relationship graph;
- memory and knowledge;
- multiplayer authority.

Cast state feeds:

- ordinary-life scenes;
- profession invitations;
- trust and refusal;
- warnings;
- evacuation decisions;
- survivor groups;
- mobile-base residents;
- later settlements and lineages.

# 3. Attachment Dependencies

Attachment depends on:

- embodiment;
- tactile work;
- recurring place;
- distinctive people;
- aspiration;
- pleasure and humor;
- personal expression;
- sensory identity;
- unforced time.

Attachment feeds the meaning of loss but may not be measured only through distress.

# 4. Warning and Knowledge Dependencies

Warnings depend on:

- sensors;
- observers;
- provenance;
- confidence;
- communications;
- trust;
- suppression;
- institutional authority.

Warnings feed preparation and NPC decisions. Simulation truth does not bypass observer envelopes.

# 5. Catastrophe Dependencies

The Breaking depends on coupled state among:

- weather and ecology;
- power and thermal systems;
- structures;
- transport;
- public trust;
- institutional conflict;
- anomaly coherence;
- hostile actors;
- responder fatigue.

The threshold event feeds:

- operational cell state;
- route graph;
- hazards;
- evacuation demand;
- public record;
- later Firstlight simulation.

# 6. Evacuation Dependencies

Evacuation depends on:

- route capacity;
- household and care groups;
- warning received;
- transport access;
- profession and duty;
- mobility support;
- trust;
- player preparation;
- vehicle readiness;
- destination capacity.

Evacuation feeds the survivor ledger. It may not teleport people or silently resolve missing as dead.

# 7. Continuity Dependencies

Continuity objects include:

- people and source chains;
- tools;
- medicine;
- archives;
- credentials;
- public authority tokens;
- cultural objects;
- ecological cultures;
- evidence;
- machine bodies and cores.

Their loading depends on physical capacity, custody, ownership, access, time, and consent.

# 8. Crawler Physics Dependencies

Vehicle state depends on:

- chassis;
- component graph;
- mass distribution;
- propulsion;
- brakes and steering;
- power;
- thermal state;
- water and sanitation;
- cargo;
- residents;
- damage;
- repair;
- route geometry.

Crawler state feeds:

- handling;
- route choice;
- resident safety;
- workshop and care capability;
- camp deployment;
- economy;
- convoy formation.

# 9. Home and Governance Dependencies

Mobile home state depends on:

- personal space;
- resident rights;
- shared resources;
- work shifts;
- privacy;
- conflict;
- module claims;
- cultural practice;
- ordinary life.

Governance feeds authority over route, supplies, guests, public services, and modification. Player control is bounded by actual office and agreements.

# 10. Persistence Levels

Full-detail simulation owns current embodiment, loading, repair, driving, and social scenes.

Operational simulation owns nearby routes, convoy, work shifts, and active projects.

Historical simulation owns distant Firstlight, separated survivors, institutions, and mobile-base change while inactive.

Promotion must preserve identities, objects, damage, claims, and causal history.

# 11. Multiplayer

Shared worldline authority must synchronize:

- cast ledger;
- warnings;
- catastrophe event graph;
- routes;
- people;
- cargo;
- crawler component graph;
- survivor outcomes;
- handoff and host migration.

No client may privately regenerate public residents or inventory.

# 12. Evidence Spine

```text
fixed seed
→ generated cast evidence
→ interaction trace
→ warning and preparation trace
→ threshold causal graph
→ route and survivor ledger
→ crawler load and physical state
→ departure state
→ replay checksum
→ player recall evidence
```

## Map Maxim

> **The opening works only when one person's remembered habit, one failed public system, one closing road, and one overloaded axle belong to the same causal world.**
