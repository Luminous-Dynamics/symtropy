# Canon Registry and Document Governance

## Purpose

This document identifies the current canonical decision spine and integrates the v2.5 worldline-character campaign without confusing account access, character authority, Chronicle knowledge, worldline truth, or verified implementation.

# Status Vocabulary

- `canonical` — current binding design authority;
- `canonical-draft` — binding direction pending implementation evidence or final review;
- `implementation-spec` — concrete runtime or production design, not proof of code;
- `lore-canonical-draft` — approved worldbuilding direction subject to content validation;
- `supporting` — context that does not override the decision spine;
- `superseded` — retained for history but no longer current authority;
- `archived` — preserved artifact outside active design;
- `unclassified` — legacy document not yet migrated.

# Authority Order

When documents disagree, use:

1. safety, dignity, consent, and rights constraints;
2. authoritative world-state, identity, chronology, and multiplayer truth;
3. current canonical contracts;
4. current implementation specifications;
5. production standards and benchmarks;
6. lore and content bibles;
7. supporting and historical documents.

A newer version supersedes an older version only through explicit metadata or registry decision.

# Core Authority Boundaries

## Account Access Is Not Character Authority

Authentication or save ownership does not create diegetic rights.

## Chronicle Truth Is Not Character Knowledge

The interface may preserve branch and roster information while clearly marking what the current character can use.

## Handoff Is Not Teleportation

The target character resumes from their actual location, body, work, obligations, and proper time.

## Inactivity Is Not Stasis

Playable characters continue living when not controlled.

## A House Is Not Its Leader

Membership, dissent, care, labor, and class remain distinct.

## Inheritance Is Domain-Specific

A will may transfer private property. It does not transfer another person's consent or a public mandate.

## Reconstitution Does Not Rewind History

Recognition of identity does not erase lawful succession or restore expired relationships.

## Political Drama Does Not Require Betrayal

Orderly succession, public administration, worker action, compromise, and voluntary retirement are fully valid dramatic outcomes.

## Worldlines Do Not Merge by Convenience

Characters and assets in divergent histories remain separate.
