# System Interaction and Dependency Map

## Purpose

This map identifies the minimum cross-system truth required for Firstlight to feel alive for ten to forty hours.

# 1. Opening Causal Spine

```text
player input
→ embodied action
→ material state change
→ NPC and institutional response
→ record and memory
→ changed place or relationship
→ later revisit
→ player interpretation and next desire
```

Every link must be implemented. A break creates either weightless action or unexplained consequence.

# 2. Embodiment Dependencies

Embodiment depends on:

- responsive input;
- body state;
- movement;
- tool contact;
- camera comfort;
- sound and haptics;
- inventory and carry;
- injury;
- accessibility.

Embodiment feeds:

- profession execution;
- combat;
- rescue;
- traversal;
- social positioning;
- evidence provenance;
- source-chain continuity.

# 3. Worldspace Dependencies

Worldspace depends on:

- terrain;
- weather;
- water;
- structures;
- utilities;
- transport;
- access authority;
- schedules;
- audio zones;
- persistence.

Worldspace feeds:

- place memory;
- route choice;
- profession cases;
- danger;
- ordinary life;
- institutional geography;
- secrets;
- absence change.

# 4. Profession Dependencies

Maintenance requires:

- material state;
- tools;
- acoustic and thermal cues;
- isolation;
- service dependencies;
- handover;
- later inspection.

Medicine requires:

- body state;
- consent;
- privacy;
- supplies;
- transport;
- household and institutional context;
- follow-up.

Civic witness requires:

- observation;
- records;
- time;
- custody;
- privacy;
- testimony;
- claim confidence;
- public procedure.

All three depend on IRIS without yielding authority to it.

# 5. Action Dependencies

Danger and combat depend on:

- movement feel;
- threat objective;
- cover and material response;
- weapon and tool state;
- companion initiative;
- damage;
- rescue;
- retreat;
- persistence;
- aftermath.

Destruction feeds:

- routes;
- services;
- evidence;
- injuries;
- repair projects;
- public claims;
- local memory.

# 6. NPC and Companion Dependencies

NPC continuity depends on:

- schedule;
- profession;
- household;
- independent project;
- memory provenance;
- availability;
- relationships;
- boundaries;
- health;
- location.

Companion coordination depends on repeated shared procedures and explicit scope.

# 7. IRIS Dependencies

IRIS depends on:

- sensor access;
- records;
- character knowledge;
- privacy permissions;
- source-chain state;
- configuration;
- current urgency.

IRIS feeds:

- orientation;
- profession support;
- uncertainty;
- memory;
- accessibility;
- return summary.

IRIS may not read simulation truth directly when the character lacks access.

# 8. Institution Dependencies

The clinic, utility, transit, public record room, venue network and hearing process depend on:

- staff;
- budgets;
- schedules;
- buildings;
- authority;
- public trust;
- records;
- supply chains;
- labor.

Institutional outcomes feed daily life and do not exist only as dialogue scenes.

# 9. Ordinary-Life Dependencies

Markets, meals, music, games, cleanup, childcare and quiet time depend on:

- time of day;
- people;
- food and utilities;
- transport;
- cultural practice;
- safe space;
- labor;
- player pacing.

Ordinary life feeds attachment and world legibility.

# 10. Campaign Dependencies

Opening campaigns arise from:

- actual system state;
- authored prerequisites;
- NPC intentions;
- institutional pressure;
- player promises;
- place history;
- weather;
- profession outcomes.

Campaigns feed:

- changed routes;
- records;
- relationships;
- projects;
- public interpretation;
- absence outcomes.

# 11. Pacing Dependencies

Pacing uses:

- urgency class;
- active intention;
- current danger;
- tutorial state;
- requested quiet;
- session stop points;
- opportunity validity.

Pacing may change presentation but not fabricate causal stakes.

# 12. Persistence and Replay

Authoritative persistence must include:

- player body and possessions;
- tool wear;
- repairs;
- injuries;
- NPC state;
- memories;
- records;
- service state;
- structural damage;
- routes;
- projects;
- campaign events;
- absence progression;
- accessibility and IRIS configuration.

# 13. Research Dependencies

Player-love claims require:

- signed build;
- session trace;
- qualitative interview;
- delayed recall;
- assistance profile;
- performance evidence;
- privacy consent;
- issue provenance.

# 14. Promotion Graph

```text
movement and contact
→ Bent Feeder
→ Commons and three doors
→ profession cues
→ Bridge Seven
→ ordinary evening
→ Lower Works
→ project and companion coordination
→ Firstlight Night
→ aftermath and hearing
→ absence and return
→ delayed recall
```

# 15. Explicit Non-Substitutions

- Lore does not substitute for recurring NPC behavior.
- visual polish does not substitute for movement feel;
- procedural population does not substitute for six memorable people;
- cutscenes do not substitute for action;
- a quest log does not substitute for discovery;
- economy graphs do not substitute for visible daily life;
- consequence dialogue does not substitute for persistent damage;
- session length does not substitute for player love.

## Map Maxim

> **Firstlight becomes a game when action, matter, people, memory, and return all describe the same event.**
