# Symtropy Documentation Changelog v2.5

## Added

- multi-character, worldline, and perspective-authority contract;
- character roster, handoff, inactive continuity, and multiplayer custody runtime;
- observer knowledge, provenance, knowledge-time, and anti-metagaming runtime;
- households, lineages, dynasties, guilds, and civic succession contract;
- domain-specific inheritance, office, property, reconstitution, and claims runtime;
- seed-vessel generation and founder-lineage atlas;
- Atlas route-house, chokepoint, diplomacy, and blockade atlas;
- relationship, adoption, apprenticeship, ward, and hostage guardrails;
- twenty-four political campaign packets;
- three-generation interstellar succession benchmark;
- JSON schemas and validation profile;
- implementation ticket backlog;
- updated canon registry, dependency map, roadmap, and readiness matrix.

## Core Change

One account may contain many playable characters, but no universal diegetic wallet, inventory, knowledge base, reputation, office, or source chain.

## Evidence Boundary

The campaign is documentation-complete and implementation-unverified.

All new capabilities remain D3 / I0.
